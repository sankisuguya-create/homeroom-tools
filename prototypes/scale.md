# 評価スケールの仕様

案2以降の共通仕様。両プロトタイプ（`grid-sheet.html` / `teacher-view.html`）が同じ規則で動く。

## 何を測っているか

**「主体的に学習に取り組む態度」**。粘り強さ・自己調整・やる気を、ノートの記述から見取って記録し、期末の評定に使う。

到達度（知識・技能／思考・判断・表現）ではない。この一点が集約規則を決める（下記「D と 休」）。

## 記号と内部値

基本字は5つ。それぞれに `−` / 無印 / `+` / `++` の4つのニュアンスが付く。**入力語彙は20記号**。

```
D−  D  D+  D++
C−  C  C+  C++
B−  B  B+  B++
A−  A  A+  A++
Z−  Z  Z+  Z++
```

**4つのニュアンスはすべて別の段**。基本字の位置を掛けて 1〜20 になる。

これとは別に、**スケール上の位置を持たない記号が2つ**ある。

| 記号 | 意味 | 誰の都合か |
|---|---|---|
| `休` | 児童がいなかった | 児童側の欠測 |
| `/` | その授業を評価に含めない（行事・テスト・予備時間など） | 授業側の都合 |

どちらも集計から外すが、**理由が違うので分けて数える**。まとめて「欠測」にすると、「休みが多い児童」と「評価しない授業が多い単元」が区別できなくなる。

**`/` は教師だけが設定する。** 授業側の都合で決まるものなので、児童のプルダウンには出さない（すでに入っているセルでは、値が消えないよう選択肢に残す）。授業単位で決まることが多いので、教師画面の**一斉入力で全員に入れる**のが典型的な使い方。

| | − | 無印 | + | ++ |
|---|---|---|---|---|
| D | 1 | 2 | 3 | 4 |
| C | 5 | 6 | 7 | 8 |
| B | 9 | 10 | 11 | 12 |
| A | 13 | 14 | 15 | 16 |
| Z | 17 | 18 | 19 | 20 |

`A++`（16）は `A+`（15）と `Z−`（17）のあいだに座る。

### 基本字は上に足せる

`Z` の上にさらに上位の字（`Y` など）が要る日が来ても、**`BASES` の末尾に足すだけで通る**。内部値は `基本字の位置 × 4 + ニュアンス + 1` で決まるので、末尾に足しても既存の段の値は動かない。評定のしきい値も記号から引いているのでずれない。

```js
const BASES = ["D","C","B","A","Z"];       // ← ここに "Y" を足す
```

**途中に差し込んではいけない。** 既存の内部値が全部ずれて、過去の記録の意味が変わる。追加は末尾だけ。

層の境目も定数で持つ。`Y` を足せば `Y` も自動で突破層に入る。

```js
const TOP_FROM = "Z";   // これ以上は突破層（箔をかける・突破回数に数える）
const WARN_TO  = "C";   // これ以下は警告層（文字を赤にする）
```

コードのどこにも `"Z"` を直接書かない。書いた瞬間、基本字を足したときにそこだけ取り残される。

`++` は「あとちょっと！」を伝えるための表示上の区別であって、順序としては `+` と同じ位置にある。**保存は記号の文字列で行い、計算のときだけ値に変換する。** 逆にすると `+` と `++` の区別が消える。

## 中央値が段の間に落ちたとき

単元評価は中央値で出す。偶数個のときは2段の中間に落ちるが、順序尺度なので平均は取れない。**下側を採る**（水増ししない）。

以前は `++` を `+` と同値にしていたため、「`+` と次の文字の中間」を `++` で表す特別扱いを置いていた。**`++` を独立した段にしたことで、この特別扱いは不要になった。** 中央値が16に落ちれば、そのまま `A++` と出る。

## D と 休（既定を反転した）

初期の設計では「D は到達度の欠測だから除外する」としていた。**これは到達度を測る前提での判断で、誤りだった。**

測っているのが態度なら、**D「やるべきことを何もしていない」は欠測ではなく、態度についての最も重い観測値**。除外すると評価対象そのものを捨てることになる。

| 記号 | 意味 | 集計 |
|---|---|---|
| `D` 系 | やるべきことをしていない | **含める**（態度の観測） |
| `C` 系 | 到達していない | 含める |
| `休` | 児童がいなかった | **常に除外** |
| `/` | その授業を評価に含めない | **常に除外** |

D を除外する設定も残してあるが、既定は「含める」。

## 集約の規則

- **平均は取らない。** 順序尺度なので D→C の幅と A+→Z− の幅が等しい保証がない。
- 既定は**後半1/3の中央値**。単元は積み上げ構造で、態度も単元前半は様子見になりやすい。この既定は教師が変更できる。
- `休` と `/` は分母からも外す。入力数は「入力 12/16、休 2、/ 1」のように分けて出す。

## 期末評定への写像

**日々つける記号は、児童のやる気を引き出すために実態より上へ振ってある。** したがって記号と評定は一致しない。実際に A 評定になるのは `A+` 以上。

単元評価（15段）→ 評定 A / B / C。しきい値は教師が動かせる。既定は次のとおり。

| 内部値 | 記号 | 評定 |
|---|---|---|
| 15〜20 | A+ / A++ / Z系 | **A** |
| 9〜14 | B系・A− / A | **B** |
| 1〜8 | C系・D系 | **C** |

記号の `A` や `A−` は評定では **B** に落ちる。ここを取り違えると評定が一段甘くなる。

**以前このメモに「基本字がそのまま評定になる」と書いたが、これは誤り。** 上振れを知らずに書いた記述で、偶然の一致を根拠と取り違えていた。

**B と C の切れ目は `C++` 以下が C。** C 評定は「ノート評価で C・D が続き、代表値が C 帯に入った児童」だけという運用と一致する。上振れは上位帯だけの現象で、下位帯は実態どおり付けている。

### 分布の目安

| 評定 | 目安 |
|---|---|
| A | 3割ほど |
| B | 7割ほど |
| C | いるかいないか（0〜1名） |

教師画面の「期末評定」タブに実際の分布を出す。目安から外れた数字は赤で表示されるので、しきい値を動かして合わせられる。この目安は担任の実感によるもので、集団が変われば動く。

複数単元のまとめ方は、単元評価の中央値（既定）／最頻値／最後の単元、から選ぶ。

### 学期

単元は `学期`（1／2／3）を属性として持つ。期末評定は**選んだ学期の単元だけ**で計算する（学年末を選べば全学期）。採用した評定は `教科 × 学期` ごとに分けて持つ。

切れ目を「どの単元で区切るか」という別データにすると、単元を並べ替えたり削除したときに切れ目だけが取り残されて壊れる。**学期が単元自身に付いていれば整合が崩れない。**

設定画面で次を検算する。

- 学期が No の順に戻っていないか（1学期 → 2学期 → 1学期）
- 同じ学期の単元が No の上で連続しているか

## 観点タグは廃止

当初は授業ごとに3観点のどれかを持たせる設計だったが、全授業が態度の観測なのでタグは常に同じ値になり、情報を持たない。廃止した。

態度の2側面（粘り強さ／自己調整）を軸として分けるかどうかは未決。

## 色

**評価の色**：`A` 系と突破層にだけ色を置く。`B` 系は無色、警告層（`D`/`C`）は塗らずに文字だけ警告色。

スケール外の2記号は**同じ地色**にする。集計での扱いが同じだから。違いは中身で示す。

- `休` は文字で書く
- `/` は**文字を出さず、欄を斜めに1本の線が横切る**。「この欄は無い」ことを線そのもので示す

閉じた `select` は選択中の選択肢の文字をそのまま出すので、`/` のときは文字色を透明にしている。開いたリストの中では `option` 側の色が効くので読める。

**装飾は基本字ごとに1つ。段（`−` / 無 / `+` / `++`）では変えない。**

| 基本字 | 見た目 |
|---|---|
| `Z` 系 | 金の箔。粒・斜めの走査光・地のグラデーションを背景レイヤで合成し、走査光を流す |
| `Y` 系 | 宇宙。ほぼ黒の地に星を散らし、紫と青の星雲をゆっくり流す |

段ごとに装飾を変える案（`Z+` だけ虹にするなど）は一度作って戻した。段が増えるたびに新しい装飾を考えることになり、**基本字を足せる設計と噛み合わない**。字ごとに1つなら、字を足すときに1つ決めれば済む。

```js
const BASE_LOOK = { "Z":"foil-gold", "Y":"foil-cosmic" };   // 未登録の字は金の箔
```

**単元評価の見せ方**：単元カードの値は、プルダウンと同じ形の枠に入れ、**1段階上の基本字の材質**で塗る。`A` なら `Z` の金の箔、`Z` なら `Y` の宇宙。

単元で高い値を取るのは1時間で取るより難しいので、同じ記号でも授業のセルより上に見えるようにする。文字色だけを変える案は採らなかった。上位の材質は箔や宇宙で、これは背景であって文字色では表現できないため。

枠は**授業セルのプルダウンと同じ縦横比（約3:1）**にし、幅だけを大きくする。形が同じなら「同じ種類のもの」と読めるので、大きさの差がそのまま格の差になる。**上端の単元色は枠に置かない。** 単元はカードそのものが表しているので、カード上端の色で足りる。枠にも置くと同じ情報が2回出る。

**ただし警告帯（`D`・`C`）は上げない。** 上げると「単元で C だった」という警告が消える。上げる操作は達成の方向にだけ意味を持つ。

**単元の色**：プルダウンの上端 3px（border-top）だけを単元の色にする。単元カードの上端にも同じ色を置き、表とカードが色で対応する。

**20色**を巡回する。色相を 126° ずつ飛ばしてあるので、**連番の単元が隣り合っても色が近づかない**（20 と 126 は互いに素なので、20色すべてが異なる）。明度は色相ごとに補正して、黄が浮いて青が沈むのを抑えてある。

**セルの地は常に紙**（確定済みセルと同じ）。単元も状態もプルダウンの上に載せることで、セルの地色というチャネルを空けたままにしてある。

**セルの状態**：状態には色を使わない。**半透明の斜め縞を「まだ変えられる」の印にする**。縞は透明度でつくってあるので、評価の色（青・金）の上でも透けて見える。

| 状態 | 見え方 |
|---|---|
| まだ変えられる（未記入・入力済みとも） | プルダウンに斜めの薄い縞。未記入は左右下の枠が破線 |
| 確定（ロック済み） | 紙のまま。印は置かない |
| これから | グレー・操作不可 |
| 教師が確定済みを開いている | 枠が破線（本来は閉じている、の意） |
| 教師が貫通して書き換えた | セル左端に細い線が残る |

## ロック

**ロックは状態として持たず、保存時刻から毎回引く。**

```
直近の境界 = 今日の定時（すでに過ぎていれば今日、まだなら昨日）
ロック済み ⇔ その評価の保存時刻 < 直近の境界
```

日次トリガでフラグを書き込む方式にしない理由：

- トリガが落ちた日に全員のロックが飛ぶ。時刻の関数なら落ちようがない
- 書き戻す状態がないので、シートとフラグの不整合が起きない
- 過去の任意時点のロック状態を後から再現できる

未入力のセルはロックしない（保存時刻がないため）。休んだ児童が後日入力できる。

**ロック後に直す必要が出たときは、教師が貫通して直す。** 児童に解除の手段は持たせない。持たせると「一度出したら直せない」という前提が崩れ、転写がやり直し前提の作業になる。

**教師アカウントはロックを貫通する。** ロック済みセルも編集でき、貫通して書き換えた記録はセルに印が残る。判定は Google アカウントで行い、UI の役割切り替えはプロトタイプ用の仮のもの。

定時（既定 17:00）は教師画面で変更できる。

## 教科

教科は教師が足せる。**足した教科は最初、児童の画面に出ない。** 単元と授業の区切りを入れ終わるまで児童に見せると、色も単元名も付かない空の表を転写させることになる。

| 状態 | 児童 | 教師 |
|---|---|---|
| 公開 | タブに出る | タブに出る |
| 非公開 | **出ない** | 灰色の斜体でタブに出る |

公開の切り替えは教師画面のタブ横のボタン1つ。切り替えた教科はその場で児童のタブに出る。

**非公開はサーバ側でも弾く。** タブを出さないのは操作の誘導であって権限の実装ではない。児童からの保存要求に非公開の教科が来たら断る。

現在の教科：算数・国語（公開）／体育・社会（非公開）。

## 全員への一斉入力

教師画面から、単元内の1授業を選んで29名全員に同じ値を入れられる。学級閉鎖・行事・出張など、全員が同じになる日のための機能。

- 既定の対象は**空欄の児童だけ**。上書きは明示的に選んだときだけ行う
- ボタンには実際に入る人数が出る（`23名に入れる`）
- 実行後に「うち上書き ◯」を報告する

上書きは取り消せないので、既定を安全側に置いてある。
