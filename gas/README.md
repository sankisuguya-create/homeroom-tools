# GAS 側

`prototypes/` を Google Apps Script に載せたもの。**いまは Step 3 まで**（シートを作る・スケールを移す・誰が開いているかを判定する）。手順の全体は [`../docs/implementation-plan.md`](../docs/implementation-plan.md)、仕様は [`../docs/spec.md`](../docs/spec.md)。

## 貼る前に手元で確かめる

```
node gas/localcheck.js
```

Apps Script の API を偽物に差し替えて、`.gs` を全部1つのスコープに読み込んで走らせる。GAS も同じく全ファイルが1つのスコープを共有するので、**ファイル間の参照ずれもここで出る**。Google のアカウントは要らない。

タイムゾーンは検査側で `Asia/Tokyo` に固定してある。UTC のまま回すとロックの検査が落ちる。**それは検査の不備ではなく、`appsscript.json` の `timeZone` が要る理由そのもの。**

## ファイル

| | |
|---|---|
| `appsscript.json` | タイムゾーンとデプロイ設定 |
| `Scale.gs` | スケールの定義（**生成物**） |
| `scale.html` | 同じものをクライアントへ（**生成物**） |
| `Setup.gs` | シート7枚を作る・検算する |
| `Config.gs` | 設定シート。5分キャッシュ |
| `Roster.gs` | 名簿。メール → 児童ID |
| `Master.gs` | 教科・単元・授業マスタ |
| `Lock.gs` | ロックの境界 |
| `Code.gs` | `doGet`・役割の判定 |
| `hello.html` | Step 3 の確認画面 |
| `localcheck.js` | 手元での検査 |

**`Scale.gs` と `scale.html` は直さない。** どちらも `prototypes/src/scale.js` から `python3 build.py` が作る。直すと次のビルドで消える。

手順書には `eval` でスケールを読む書き方を載せていたが、**トップレベルの `const` が `eval` の外に出ない場合があるので、実ファイルを2つ生成する形に変えた**。中身は同じ1つの元から出ている。

## 置き方

1. スプレッドシートを新規作成する（教師のアカウントで）
2. 拡張機能 → Apps Script
3. プロジェクトの設定で「`appsscript.json` を表示する」にチェック
4. このフォルダのファイルを同じ名前で作って中身を貼る
   - `.gs` はスクリプト、`.html` は HTML ファイルとして作る
   - `localcheck.js` は貼らない（手元専用）
5. `setupSheets` を実行 → シート7枚ができる
6. **設定シートの「教師メール」に自分のメールを入れる**
7. 名簿・教科マスタ・単元マスタ・授業マスタを埋める
8. `clearAllCache` を実行（5分待たずに反映される）
9. デプロイ → 新しいデプロイ → **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**同じ組織内の全員**

`appsscript.json` に `executeAs: USER_DEPLOYING` / `access: DOMAIN` を書いてあるので、画面の既定もこの組み合わせになる。**それでも一度目で確認する。** ここを間違えると児童全員にシートの編集権限が渡り、あとから直せない。

## Step 3 の確認（ここが通らなければ先へ進まない）

デプロイした URL を **児童アカウント1つで実際に開く**。

| 出るはず | 意味 |
|---|---|
| こんにちは、◯◯ さん／児童 | メールが取れて名簿と照合できた |
| メール欄に本人のアドレス | `Session.getActiveUser().getEmail()` が通った |
| 見える教科：算数、国語 | 非公開の教科が児童に渡っていない |
| 往復テスト：○ | スケールがサーバ・クライアント両方で同じ |

**「メールが取れていない」と赤く出たら、そこで止める。** 組織のポリシーで `getActiveUser()` が空を返す設定になっている。以降の設計（本人確認・ロック・貫通）がすべてこの1点に乗っているので、先に進んでも積み上がらない。

教師アカウントで開くと「先生／教師」、名簿にも教師メールにも無いアカウントでは「だれか わかりません」と出る。**3つとも試す。**
