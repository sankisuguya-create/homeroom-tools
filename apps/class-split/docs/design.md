# クラス替え 設計

職員が使う、学年の児童の **配慮・生徒指導の情報を記録し、学年をまたいで引き継ぐ** 道具。クラス替えは、その情報を年に1回使う場面の1つ。
この文書は、決めたことと理由の正本。同じ議論をやり直さないために、理由（なぜ）を残す。

### 位置づけ（何を持ち、何を持たないか）
- **持つ**：C4th（校務支援システム）に載らない、担任の判断と生徒指導の記録。配慮項目の程度、つける・離す、備考、事案（関係図・役割・期間・詳細・文書へのリンク）。
- **持たない（借りるだけ）**：学籍（氏名・よみ・性別・学年・組・番号）。正本は C4th。名簿は貼り付けで取り込む。ここで学籍を直して C4th と二重に持たない。
- **C4th との連携の向き**：入れるのは身元の情報（名簿）、出すのはクラス替えで決めた組・番号。
- 新しい機能は「C4th に無く、配慮・生徒指導の引き継ぎかクラス替えに要るか」で採否を決める。学籍・成績・出欠・保健など C4th が正本のものは持たない。
- 日常の入口は名簿（メニューで「名簿を見る」を大きくした）。クラス分けは学年末の作業。

| 名簿 | 年度タブ（過去の年度・今年度・決定後は準備中の年度）× 範囲（組／学年／全校の事案）。配慮項目のマスはタップで 空→1→2→3→空（自動保存）。「事案のある児童だけ」「件数の多い順」。名前を押すと右に、経年の記録（年度ごとの学年・組・番号・各項目の程度・事案数）と事案の一覧・登録 |

### クラス分けの盤面
- 教師PCの全画面で、最大4学級×36人の全員を1画面に収める。各学級は旧学級・番号の順に2列へ詰める（男女で列を分けない。行数が人数の半分になり、カードを最も高くできる）。行の高さとアイコンの大きさは画面から計算する（`fit()`）。
- 縦幅を最大にするため、盤面の上は1行の帯（メニューへ戻る・案のタブ・違反・保存状態・操作ボタン）だけにし（操作の説明文は出さない。「離す」の後に続けて入れ替える時だけ、誰の番かを太字で出す）、ページの見出し行は隠す。組の見出しは人数・男女・事案数と配慮項目の数だけ（旧学級・地区の内訳は出さない。偏りは△と違反の一覧で分かる）。下の凡例は配慮項目のアイコンだけ。
- 児童カード：男＝長方形、女＝ピル型。左端は旧学級の色の帯（赤1組・黄2組・青3組・緑4組）で、帯に旧番号。地は旧学級の色を薄くした色。1段目に名前と良い要素（賢・リ・運、緑）、2段目にその他の項目と事案の件数。**アイコンは項目ごとに位置を固定**し、右に詰めない（同じ項目が縦にそろう）。
- 配慮項目の印は頭文字＋色＋形の三重。形は 学＝角が欠けたボロボロの四角、問＝ちくちくした形、保＝家、リ＝旗（長方形の右端に切れ込み1つ）、通＝貝殻（紫。上下がふくらんだ横長の形）、ほかは丸・八角形・盾・五角形・平行四辺形。程度は字の右上の「+」の数（程度2＝+、程度3＝++）。9色は特例（利用者の判断）。色だけでは潰れる組（朱と茶、桃と緑など）は形と頭文字で区別する。
- 入れ替え：2人をタップ → 確認の枠（左右にカード、中央に⇄）→ Enter。組の見出しをタップすると移動。
  - **つける**：相手が同じ組にいれば一緒に動かす。数が合わない側は、偏りが最も小さくなる児童を自動で補う（「別の児童にする」Tab で次の候補）。
  - **離す**：抵触する時は、枠の中に地味な色で「離す児童と同じクラスになります。続けて離す児童の入れ替えに移ります。続行しますか？」と離す児童のカード（最大3人、それ以上は「＋ あとN人」に畳む）。続行すると離す児童を選んだ状態になる。連鎖は毎回この枠で止まり、Esc でいつでも抜けられる。
- 案を作る（G）：先に設定の枠を出す。必ず守る条件（離す・つける・組に固定・人数の上限・男女の差±1）のオン・オフと、各項目の重み（なし／弱／中／強）。**前回の設定で開くので G → Enter で同じ設定のまま作れる**（学年会で何度も作るため）。
- 案の名前：「案A（問の分散重視）」。括弧の中は設定から自動で決め、ダブルクリックで変えられる。自動の名前は後から安く直せるので自動にした（理念：後から安く直せるものだけ自動で決める）。
- 比較タブ：指標ごとに学級の最大−最小、最良に★。「所属が違う児童」は組の番号の付け替えを無視して数える。重みの設定と外した条件も並べる。
- ショートカット：Ctrl+Z／Ctrl+Y（Ctrl+Shift+Z）、Enter、Esc、1〜9、0、G、D、L、V、F、?。Ctrl+D はブラウザのブックマークなので使わない。

## 2. 年度とクラス替えの決定

- 年度の境目は4/1。`CONFIG.fiscalYear()` 1か所から出す（`principles/roster-year-transition.md` §1）。
- 配慮項目の値は **年度ごとに残す**（経年の記録のため）。確定時に消す案はやめた（§4）。
- **決定**（確認の語の入力が要る）で、1回の処理として：
  1. 来年度の名簿を作る（新しい番号は組ごとの男女混合の五十音順。読みが同じなら児童ID順）
  2. 今年度の配慮項目の値を来年度に写す
  3. つける・離すを来年度の候補として持ち越す（memo は持ち越さない）
- 決定から4/1まで：**今年度の値は凍結**し、直すのは来年度（準備中）の側だけ。両方を直せると食い違うため。
- 決定は **4/1まで取り消せる**。取り消すと来年度の名簿と写した値を消す。
- 6年は決定しない（卒業）。1年は前の年度の値が無いので、名簿を貼った後に手で入れる。

### 不変条件（`engine.checkInvariants` とテスト）
1. 1つの案で、名簿の全児童がちょうど1つの組に入る。
2. どの組も36人以下（必ず守る条件がオンのとき）。
3. 「つける」の組はまとめてしか動かない。
4. 組の事案数は、同じ事案を1件と数える。

## 4. 個人情報と開示請求

- 2023年4月から公立学校にも個人情報保護法の開示請求（76条〜）が適用される。学年で共有して使うこのデータは、組織として使う文書とみなされ得る。
- 経年の記録を残すと決めたので、確定時の消去はしない。代わりに：
  - シートの列は中立のキー（k1〜k9）。項目の名前は `settings` と `src/config.js` だけ。
  - 卒業・転出した児童は、設定の「年度替わり」で削除の候補に出し、選んで確認の語を入れてから消す（`apiPurge`）。消すのは名簿・配慮項目・つける離す・持ち越し・事案との結び付き・案の割り当て。結び付く児童がいなくなった事案は名前・URL・詳細を消して削除済みにする。
  - **保持期間**：卒業・転出から **5年度**（利用者の方針。設定の既定値）。設定で0〜6年度に変えられるが、**事案に関わった児童は設定にかかわらず5年度は候補に出さず、サーバーも消すのを断る**（`CONFIG.purgeable`）。理由：事案はいじめ等の記録を含み、保存の目安が5年とされている（文部科学省の通知と記憶しているが、通知名・年は未確認）。年数の正本は教育委員会の文書管理規程で、未確認。規程が分かったら `CONFIG.INCIDENT_KEEP_YEARS` と既定値を合わせる。
  - 事案の詳細欄・役割（加害・被害など）は開示請求の対象になりうる。詳細は事実を書き、推測や評価を書かない運用にする。中立のキーで項目名を隠す工夫は自由記述には効かない。
- 外部への通信はしない。`scripts/build.py` が dist の外部参照を検出したら生成を止める（collection-check と同じ扱い）。
- ブラウザに個人情報を残さない（校務PCは複数の教員が使う）。localStorage に置くのは、端末の画面に合わせる表示の好み（アイコンの大きさ・関係図の高さ・欄の開閉・並び順・カード表示）だけ。
- 事案の一覧の絞り込み・関係する児童の検索の設定は sessionStorage（タブを閉じると消える）。次の先生の画面に前の先生の絞り込みが残らないように。
- 保存の決まり：押すだけの操作（名簿のマス・状況のボタン・案の編集）はすぐ保存。文字を書く窓は「保存」ボタンで保存（事案の記入は書きかけも自動で残す）。保存に失敗したら間を延ばして6回まで送り直し、だめなら閉じるまで消えない知らせで「もう一度」を出す。
- 同時に直した時：案・つける離す・事案は版を照らし、ほかの先生が先に保存していたら上書きせずに知らせる。
- 個人情報の置き場の一覧は [pii-map.md](pii-map.md)。

## 5. 実行の形（本番。PR② で作った）

- GAS の Webアプリ1本。「自分（所有者）として実行」、ドメイン内に公開し、サーバー側で `@edu.nishi.or.jp` を確認する。データのシートを教員に共有しないで済むため。
- 計算と描画はブラウザ。サーバーは読み込み（学年ごとに1回）と保存だけ。保存は操作を即座に画面に反映し、背後で送る（失敗したら再試行し、画面上部に表示。送れていない保存がある間に閉じようとするとブラウザが確かめる）。
- 事案の文書の名前は、登録の時に1回だけ所有者の権限で取る。所有者が開けない文書は取れないので、手で入力してもらう。
- 版の照合：`scripts/build.py` が `dist/gas/` 一式の内容のハッシュを `SERVER_BUILD`（Code.gs）と `PAGE_BUILD`（Index.html）に焼き込む。食い違えば画面の上に警告（`principles/gas-javascript-notes.md` §4。note-assessment と同じ方式）。
- サーバーは画面と同じ `config.js`・`engine.js` を Code.gs の先頭につないで使う（決定の時の番号の振り方を1か所にするため）。
- 画面から呼ぶ関数は `apiXxx`。戻り値は JSON の文字列 `{ok, build, v | err, user}`。`user` の誤り（権限・凍結・同時保存など）は画面が再試行せずに知らせる。
- 書き込みはスクリプトロックの中で行い、書き戻しは変えたセルだけ（`writeCell_`）。

### 実機で確かめること（PR② では未確認）
1. 「自分として実行」で、同じドメインの教員のメールが `Session.getActiveUser()` で取れること（取れないと誰も開けない）。児童のアカウントで開くと拒否されること。（教員の判定は `currentTeacher_`：ドメインが `edu.nishi.or.jp` ちょうどで、児童のドメイン `kyoiku.edu.nishi.or.jp`・数字8桁の名前でないこと。児童のドメインは教員のドメインの末尾と重なるので、末尾の一致だけで判定しない）
2. `drive.readonly` の権限で `DriveApp.getFileById().getName()` が動くこと。所有者が開けない文書で空が返ること。
3. 2人が同時に案を保存した時に、後の人に「先に保存しました」が出ること。
4. 学年を開く時間（目安2秒以内）。
5. 報告書の Excel（`apiExportReport`）：`Utilities.unzip` / `Utilities.zip` で xlsx の中の道筋（`xl/worksheets/…`）が保たれ、Excel で開けること。様式のファイルは xlsx のまま（スプレッドシートに変換しない）ドライブに置く。書き込んだ複製は様式と同じフォルダに作る（権限は `drive`。所有者として作るので、教員が開けるかはフォルダの共有で決まる）。
- 配色は明るい1種に固定。色覚の検証と投影を白地で行ったため。

## 6. 軽さ（測った結果と決めたこと）

CPU を1/4に落とした Chromium（低性能端末の代わり）、144人の盤面で測った。

| 操作 | 改善前 | 改善後 | 何をしたか |
|---|---|---|---|
| 児童を選ぶ | 約990ms | 約55ms | 盤面を作り直さず、選択・離す/つけるの印・見出し・案内の文だけを書き換える（`updateSel`） |
| 盤面を描き直す（入れ替え後など） | 約1070ms | 約270ms※ | 寸法はカードを入れる前に空の列で1回だけ測る（`fit`）。アイコンの空の枠を作らない（決まった位置に絶対配置） |
| 名簿のマスを押す | 約240ms | 約25ms | 押したマスだけ書き換える |

※ 指定した日本語フォントが端末に1つも無いと、代わりを探す処理で描画が約3倍重くなる（試験環境では約800ms）。
フォントの指定は 校務PC(Windows)→Chromebook→Mac の順に、各端末に入っている名前を先頭近くに置く。
校務PCは先頭の BIZ UDPゴシック（Windows 10 以降に標準）で軽い側になる見込み（実機未確認）。

- 日本語フォントは各端末に入っている名前を明示し、最後の汎用名（sans-serif）に頼らない。`lang="ja"` を宣言していても、指定した名前が1つも無いと汎用名が中国語のフォント（試験環境では WenQuanYi Zen Hei）に落ちた。`kbd` も等幅の汎用名をやめ、日本語の文字は同じ指定に落とす。テスト（`ui.test.mjs`）で、描画に使われたフォントに中国語のものが無いことを確かめる。
- 凡例は計測の前に書き込む（後から折り返すと盤面が縮み、最後の児童がはみ出す。実際に起きた）。
- アイコンの位置指定は既存の style 属性に足す（style 属性が2つあると後ろが無視され、色が消える。実際に起きた）。

## 新しい組の名前（A組・B組…）

クラス分けの枠は A組・B組… で示す（旧学級の1組・2組… と取り違えないため）。組の番号は決定の後に「組の番号を決める…」で別に決める。決めるまでは仮で A組＝1組…。決めると来年度の名簿の組の列だけを付け替え、出席番号（組の中の五十音順）は変えない。番号は decisions の names 列（A組から順、空＝仮）に持つ。枠の地は旧学級の色と混ざらないよう、色相の無い灰の濃淡を交互にする。
