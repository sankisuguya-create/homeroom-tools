# 端末の確かめ（device-probe）

クラス替えの「端末の登録」を作る前に、次の2点を実機で確かめるためのページ。本番のプロジェクトとデータには触れない。個人情報は扱わない。

1. GAS の画面に保存した値（合い言葉の代わり）が、タブを閉じても・ブラウザを再起動しても残るか
2. 端末の種類の判定（OS・携帯向けかどうか・画面の大きさ・タッチ点数）が想定どおりに出るか

## 貼り方
1. 新しい Apps Script のプロジェクトを作る（本番とは別）。
2. `Code.gs` を `コード.gs` に全文、HTML ファイル `Index` を作って `Index.html` を全文。
3. デプロイ → 新しいデプロイ → ウェブアプリ。実行するユーザー「自分」、アクセスできるユーザー「（ドメイン）内の全員」。
4. 出た URL を、確かめる端末で開く。

## 確かめる端末と、知らせてほしいこと
| 端末 | 期待 |
|---|---|
| 教師用 Chromebook（CZ1104） | 登録できる・①②で同じ値 |
| Dynabook（Windows） | 登録できる・①②で同じ値 |
| 自分の iPhone（ふつう／「PC版サイトを表示」） | 両方とも弾く |
| （あれば）Android（ふつう／「PC版サイトを表示」） | 両方とも弾く |

各端末で、表の値（判定・OS・携帯向け・画面・タッチ点数）と、①②の結果を知らせる。ブラウザの再起動の後の②も。
