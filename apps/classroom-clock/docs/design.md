# 教室の時計 — 設計の決定

## 1. 類似アプリから引いた要件
- Classroomscreen：時計（デジタル・アナログ）、タイマー、ストップウォッチ、信号、騒音計を1画面に並べる。→ 機能の範囲の目安にした。部品を並べ替える盤面の形は採らない（毎回の配置が判断を増やす。設計理念 原則1）。
- Time Timer・時っ感タイマー：残り時間を減っていく色の面で見せる。→ アナログ盤の扇形。超過表示は利用者の指定で採らない。
- Twinkl：残量で緑→黄→赤。→ 色に加えて言葉（残り／残りわずか／終了）と面の大きさで伝える（color-coding）。
- 視覚タイマーの効果は、調べた範囲ではメーカーの主張と実践報告が中心（独立した研究は未確認）。

## 2. 決めたこと
| 決定 | 理由 |
|---|---|
| 操作の画面と、モニターに映す面を別の窓にする | 利用者の要望「操作の部品はモニターに出さない」。ミラーリングでは手元とモニターが同じ画面なので原理的に分けられない。拡張でつなぎ、映す面だけを別窓で開く |
| 映す面の描き方は1つ（view.js）で、手元の見本とモニターの両方を描く | 見本とモニターが食い違わない |
| Chrome の画面配置（getScreenDetails）が使えれば、窓をモニターへ自動で置き、そのモニターで全画面にする | ドラッグで窓を運ぶ手間をなくす。許可されなければ通常の窓で開く |
| 全画面はモニター側の窓を1回押してから | ブラウザは、その窓での操作なしに全画面にさせない |
| 残り・経過は時刻の差から出す | タブが裏に回って処理が間引かれても、読み込み直してもずれない |
| 5秒より遅れて気づいた合図は鳴らさない | スリープ明けに古い合図をまとめて鳴らさない |
| 残りは秒を切り上げて表示する | 0:00 が出るのは終わってからだけにする |
| 予告（残り1分）は2分以上のタイマーだけ | 1分タイマーで開始と同時に予告が鳴るのを防ぐ |
| 音はブラウザの中で合成する | 通信なし・読み込み待ちなし・著作権の問題なし |
| 声は端末の日本語の声だけで読む | 外国語の声で日本語を読ませない。声が無い端末では設定欄に知らせる |
| 時間割の残りは60分以内だけ扇形で塗る | 長針1周で表せる範囲 |
| 同じ時刻の「おわり」と「はじまり」のチャイムは1回 | 給食→昼休みのように続く時刻で2回鳴らさない |
| 時間割は「名前 8:45-9:30」の1行1つの文字で編む | 表の部品より速く、日課表からの貼り付けもできる。全角の数字・記号も読む |
| 針は中心から先へだけ伸ばす | 反対側への突き出しは読み取りの手がかりにならず、扇形と重なって見づらい（利用者の指定） |
| 扇形は中心から円周まで塗る。終わりの位置は青い線＋円の外の赤い三角 | 面の大きさで残りを読ませ、終わりの位置を2つの印で示す（利用者の指定）。赤と青は色覚の型を問わず見分けられる（color-coding の検査） |
| 表示は デジタル／アナログ／横棒 の3つ | 横棒は時計を読めない児童にも長さで伝わる。時間割の残りにも使う |
| 操作画面の部品は design/ui-patterns の型に合わせる | 選んだ側は淡い塗り＋青枠＋✓、スイッチは「入／切」の文字つき、2値の配色はスイッチ。強い塗りは授業中にくり返す主操作（スタート）だけ |
| 数字は1字ずつ同じ幅の枠に入れる（0.64em、: と . は 0.34em） | BIZ UDPゴシックは字幅が数字ごとに違い、tabular-nums も書体が対応していないと効かない。枠に入れれば書体によらず桁の位置が動かない |
| 残り時間の塗りは濃いめ（明るい #A9CBEE・残り1分 #F7C873、暗い #1D5A96・#7A5210） | 投影すると淡い色は白に飛ぶ（color-coding）。上に載る数字とのコントラストは 10 以上を保つ。補助の文字は #4A525B（7.9:1） |
| 時間を選んでも始めない。スタートはボタン・画面クリック・スペースキー | 選んでから説明する間を取れる（利用者の指定）。画面クリックは見本・モニター（全画面後）の両方で効く |
| 終了したら 0:00 で止める（超過は数えない） | 利用者の指定 |
| 終了音は止めるまで最長30秒くり返す。操作ボタン・画面クリックで止まる | 既存のタイマーアプリ・キッチンタイマーの型。1回鳴って終わると聞き逃す |
| 終了音の既定は電子音「ピピピピッ」（2kHz の矩形波4連） | キッチンタイマー・スマートフォンのタイマーで最も一般的な型。選択肢にベル・マリンバ・学校のチャイム |
| 予告は「ピッピッ」、残り10秒は毎秒「ピッ」 | 同上 |
| 声があるときは、終了音の1回目のあとに2.6秒あけて読み上げ、そのあと繰り返しに戻る | 音と声を重ねない |
| 操作画面の語彙は大人向け（一時停止・再開・リセット・ダークモード 等） | 利用者の指定。モニターの表示も「残り／残りわずか／終了」に統一 |
| 文字盤の数字は円の外側（半径116、viewBox 272 基準）。線は 外周3・5分目盛り3・1分目盛り1.2・時針8・分針5・秒針1.5。分針は目盛りの内側まで伸ばす | 教室の後ろの席から読めるように。分針と時針は太さと長さの両方で区別する |
| 横棒の目盛りは実際の秒で位置を決める。2分以下は10秒ごとの線・30秒ごとの数字（m:ss）、それより長ければ1分ごとの線と1・5・10分ごとの数字。半端な長さは右端に m:ss を出す。延長で残りが全体を超えたら全体の長さも伸ばす | 棒の長さを「あと何分」に読み替えられる |
| モニターの表示に文を出さない（「残り」「〜まで」「一時停止中」「ストップウォッチ」等を削除）。一時停止は数字を薄く、終了・残り1分は色と音で示す。出す文字は日付・時刻・数字・時間割の名前・アラームのメッセージだけ | 利用者の指定。遠くから読むのは数字と面だけにする |
| 操作画面はアイコン＋小さな添え字（11px）。説明文はツールチップ（title）へ。操作画面の幅は 336px にして見本を広く | 利用者の指定。アイコンだけにすると初見で意味が取れない操作が残るため、添え字は消さず小さくした（設計理念 原則2）。アイコンはインラインSVGで描き、外部ファイルを読まない |
| 見た目は docs/preview の A（象牙・明るい）と B（夜・ダーク）。色は1色＋三角の赤だけ、枠線をやめて面の明暗で区切る、針は先細り、数字は細め（「数字を太く」で600に） | 利用者が A・B を採用。高級感は抑制・線の強弱・余白で出し、遠くから読む数字・針・5分目盛りはコントラストを保つ |
| 数字の書体は Segoe UI → Roboto → Helvetica Neue → Inter → 日本語書体の順 | 細い太さを持つ欧文書体を先に当てる。数字だけなので漢字の字形の問題は起きない。学校の端末での見え方は未確認 |
| 音の試聴ページ dist/sounds.html | 終了音・予告・チャイム・読み上げを鳴らし比べる。音の正本は同じ sound.js |
| タイマーの合図は区切りごと（残り1分・残り30秒・5〜1・そこまで）に音を選ぶ：女性の声／低い男性の声／ロボット／合成音（ピッピッ・ピッ）／なし。終了音は別に選ぶ | 利用者の指定。声は VOICEVOX で作った録音を埋め込む（scripts/make_voices.py）。声のデータが無い時は合成音で代える |
| 声の作り方：Open JTalk（HMM 音声合成）＋ HTS voice tohoku-f01 neutral（東北大学, CC BY 4.0）で女性の声を作り、WORLD（音声分析合成）で声の高さと響きを分けて加工して 低い男性（F0 約110Hz・響き0.8倍）とロボット（F0 平坦105Hz＋リングモジュレーション・櫛形フィルタ・ビット落とし）を作る（scripts/make_voices_hts.py） | VOICEVOX（ニューラル音声合成、品質はこちらが上）はこのクラウド環境で動かせなかった：モデル（voicevox_vvm）は git で取れるが暗号化されており、復号する実行部は GitHub のリリース配布で、この環境からは取れない。VOICEVOX を入れた私用PCで scripts/voicevox_export.py（Python 標準だけで動く）を実行して wav を voices-src/ に上げれば、クラウド側の scripts/voices_from_wav.py で差し替えられる（docs/voicevox-steps.md）（クレジット「VOICEVOX:冥鳴ひまり／青山龍星／玄野武宏」が要る） |
| 現在の声は VOICEVOX（私用PCで書き出した wav を voices-src/ に置き、voices_from_wav.py で変換）。ロボットは WORLD で高さを105Hzに固定してから加工。加工は音量をそろえてから行う | 小さい音のままビットを落とすと声が崩れて聞き取れなくなった（声の高さが検出できないほど）ため |
| 表示の形はモードごとに選べるものだけ押せる（時計：デジタル・アナログ、横棒は時間割が入の時だけ。タイマー：3つとも。ストップウォッチ：デジタルだけ）。選べない形は薄くして押せなくし、選んでいた値は覚えておく | 残り時間が無い場面では扇形も棒も描けず、選んでも何も変わらないボタンが判断を増やすため |
| 時計のアナログは、タイマーと同じく時計を左・今の時刻（時:分）を右に大きく | 利用者の指定。時計も大きく（文字盤の外の余白を詰めた） |
| タイマー・ストップウォッチの数字は 400、時計は 300（「数字を太く」で 600） | 利用者の指定。読み取る数字は少し太く |
| 外部通信なし（build.py の検査対象） | 校内で止められる経路を持たない |

## 3. 入れなかったもの
- 騒音計：今回の選択で外した。入れるならマイクの許可が要る。
- 別端末からの遠隔操作：サーバが要る。
- 信号・作業の約束カード（「となりと相談」など）：時間管理の範囲外。要望があれば足す。

## 4. 確かめていないこと
- 学校の教師用端末（ChromeOS の 4GB 機、Dynabook）で、モニター側の窓への自動配置と全画面が動くか。
- 教室のモニターのスピーカーの音量と、チャイムの聞こえ方。
