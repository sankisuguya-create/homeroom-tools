# 教室の時計

教室の大きなモニターに、時計・タイマー・ストップウォッチを映す道具。
`dist/Index.html` を教師用端末のブラウザ（Chrome）で開くだけで動く。サーバも通信も要らない。

## 使い方

1. 教師用端末とモニターを **「拡張」** でつなぐ（ミラーリング＝複製ではなく）。
   - ChromeOS：設定 → デバイス → ディスプレイ →「内蔵ディスプレイをミラーリング」を外す
   - Windows：`Windows`＋`P` →「拡張」
2. `dist/Index.html` を開き、「モニターに出す」を押す。時計だけの窓がモニター側に開く。
3. モニターの窓を1回押すと全画面になる。以後の操作はすべて手元の画面で行う。

ミラーリングのままでも使える（その場合は操作の画面もモニターに映る）。

## できること

| 機能 | 内容 |
|---|---|
| 時計 | デジタル／アナログ／横棒。日付と曜日つき |
| タイマー | 1〜45分から選んでスタート、±1分。残り1分で色と言葉が変わり、終了後は 0:00 で止まる |
| アナログ盤の残り時間 | 今の長針から終わりの位置までを、中心から円周まで扇形で塗る。終わりの位置は青い線と、円の外の赤い三角で示す |
| 横棒の残り時間 | 残りを棒の長さで見せる。60分以下なら1分ごとの目盛りつき |
| ストップウォッチ | 0.1秒単位、ラップ |
| アラーム | 時刻と言葉（例：10:25 かたづけ）。モニターに大きく出して読み上げる |
| 時間割 | 日課を一度入れると、今の時間の名前と終わりまでの残りを扇形・横棒で自動表示し、チャイムを鳴らせる |
| 音 | 終了音（電子音・ベル・マリンバ・学校のチャイム）は止めるまで最長30秒くり返す。予告音「ピッピッ」、残り10秒のカウント音。ブラウザの中で合成する（音のファイルなし） |
| スタート／一時停止 | ボタンのほか、見本やモニターの画面のクリック、スペースキーでも。鳴っている音もこれで止まる |
| 声 | 「あと1分です」「時間です」「1時間目が終わりました」。端末に日本語の声があるときだけ |
| 画面の合図 | 音と同時にモニターのふちを光らせる（消音時・聞こえにくい児童への保険） |
| 見た目 | 明るい／暗い |

設定・タイマーの途中経過はこの端末のブラウザに保存される。読み込み直しても続きから。

音は `dist/sounds.html` で鳴らし比べられる。

## 直すとき

正本は `src/`。`python3 scripts/build.py` で `dist/Index.html` が出る。
設計の決定と理由は [docs/design.md](docs/design.md)。

```bash
node --test apps/classroom-clock/tests/core.test.mjs
node apps/classroom-clock/tests/ui.test.mjs
```
