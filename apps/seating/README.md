# 席替え

Google スプレッドシートに組み込む席替えの道具。条件（離す・近く・前方・固定・男女）、児童の属性（リーダー・学習支援役・高身長・配慮）、
**過去の席替えの履歴**を同時に満たす配置を計算し、案を3つ並べる。何をどれだけ重視するかは画面で選ぶ。教員は案を見比べ、タップで入れ替え、決定するだけ。

設計と判断の経緯：[docs/design.md](docs/design.md)

## 何を解いているか

32人を32席に置く並べ方は 32! ≈ 2.6×10³⁵ 通り。「AとBを離す」「前回の隣とは組ませない」「各班に班長候補1人」
「男女交互」を同時に満たす配置を手で探すと、1つ直すと別の条件が崩れる。この道具は焼きなまし法で探し、
満たせなかった条件を**文章で名指し**する（どれを諦めたかが見える）。

## 置き方（Apps Script）

1. 学級用のスプレッドシートを新規作成 →「拡張機能」→「Apps Script」。
2. `コード.gs` の中身を `dist/Code.gs` で置き換える。
3. 「＋」→「HTML」で `Dialog` を作り、`dist/Dialog.html` を貼る。
4. 保存してスプレッドシートを再読み込み → メニュー「席替え」→「シートを用意する」（初回は承認が要る）。

`appsscript.json` は貼らなくてよい。別のスプレッドシートから取り込むため、初回の承認で「スプレッドシートの表示・編集」の権限を求められる（開くのは教員が URL を貼ったファイルだけ）。

## 使い方

| シート | 書くこと |
|---|---|
| 名簿 | 番号・氏名・性別。必要な児童だけ ✓：前方／高身長／リーダー／学習支援役／配慮。固定席は「行-列」（前から何行目-左から何席目、通路は数えない）。旧版の「班長」列はそのまま「リーダー」として読む |
| 条件 | 児童A・児童B（番号か氏名）・関係（離す／近く）・強さ（できれば／必須） |
| 配置 | ダイアログの「配置」で作る（最大 10×10、既定 8×8）。セルの値：班番号＝座席、○＝班なしの座席、空白＝通路 |
| 設定 | 男女の扱い（隣は男女／市松／班だけ／考えない）・前方の行数・履歴を見る回数・候補の数。「重視:」の行はダイアログの「重視」が書く |
| 過去の座席 | このアプリを使う前の席替えを入れる枠。番号を席の位置どおりに書き、日付を入れて、メニュー「過去の座席を履歴に取り込む」 |
| 履歴 | 「決定」時に自動で追記。手で消せば、その回はなかったことになる |
| 座席表 | 「決定」時に自動で作る。左＝児童から見た向き（掲示）、右＝教卓から見た向き |

メニュー「席替え」→「席替えを開く」。上の3つのボタンで画面を切り替える。

**配置**：ひな形（2人組×3列／4人の島／6人の島／コの字／1人ずつ）を選び、番号を選んでマスをなぞって直す。
同じ番号のまとまりの外周に太線が引かれ、座席表シートにも同じ太線が出る。

**重視**：11項目それぞれを 無視／弱／中／強／必須 から選ぶ。選ぶと今の案の点数がすぐ付け直される。

| 項目 | 何を見るか |
|---|---|
| 「離す」「近く」の組 | 条件シートの「できれば」の組（「必須」の組は常に必須） |
| 男女の混ざり方 | 設定の男女モードに従う。班の男女差も見る |
| リーダー／学習支援役を各班に | 各班に1人。人数が班の数より少ないときは「同じ班に重ならない」だけを見る |
| 配慮の児童を分ける | 同じ班・前後左右に並べない |
| 高身長は後ろへ | 前方の行に置かない（「前方」✓ の児童は除く） |
| 最近の隣／班を避ける | 履歴を見る回数ぶん。古い回ほど弱く効く |
| 前回と同じ席を避ける | |
| 前・後ろの回り持ち | これまで前方が多かった児童を前方に置きにくくする |

**取り込み**：前の学期・去年などの座席表（別のスプレッドシート）を履歴に入れる。

1. URL を貼って「開く」（空欄ならこのファイル）→ シートと範囲（空欄＝全体）を選んで「読む」
2. 格子がそのまま表示され、各セルの対応が色で出る：緑＝対応した／黄＝名前の一部から推定／赤＝対応できない
3. 赤・黄のセルは右の一覧から児童を選ぶか「飛ばす」
4. その席替えの日付を入れて「履歴に取り込む」。続けて別の回も取り込める

| 読めるセル | 例 |
|---|---|
| 番号だけ・氏名だけ・両方 | `3`／`うえだ`／`3 うえだ`／`3（改行）うえだ`／`うえだ(3)` |
| 敬称・空白の揺れ | `うえださん`、全角の数字・空白 |
| 見出し（飛ばす） | 黒板・教卓・窓・廊下・空席・欠番・座席表・第n回 など |

- 前の見出し（黒板・教卓）が座席より下にあれば「教卓側から見た表」とみなして反転する。違っていればチェックで直す。
- この道具の「座席表」シートのように向き違いの表が2つ並ぶ場合は、片方の範囲（例 `A1:H9`）を指定する（画面で警告が出る）。
- 取り込むのは「誰の隣が誰か」と席の位置。班の区切りは取り込まないので、「最近の班を避ける」には効かない。
- 席の位置は、座席の左上を配置シートの起点にそろえる。教室の形が今と違えば「前回と同じ席」の判定は目安になる。

**席替え**：「席を作る」→ 案を比べる。

- 案A〜C：点数の小さい順。タブに「気になる点」の件数。
- 席を2つ続けてタップ → 入れ替え。増えた問題に「入れ替えで増えた」と付く。
- 席を選んで「📌 この席に固定」→「作り直す」で、その席を残して残りを計算し直す。
- 「発表」：番号順に1人ずつ表示（投影用、スペースキーで次）。
- 「この席で決定」：座席表と履歴に書く。次回はこの席を「前回」として避ける。

## 決めたこと

| | |
|---|---|
| 計算の場所 | ブラウザ（ダイアログ内）。GAS の実行時間制限と往復待ちを避けるため |
| 隣の定義 | 左右に接した席（2人組の机）。前後・斜め・同じ班は別の重みで扱う |
| 履歴 | 決定したときだけ書く。没案で「前回」が汚れないように |
| 配慮・離す理由 | 座席表シートには書かない。ダイアログの中だけで表示 |
| 学力 | 段階では持たず、「学習支援役」の ✓ だけを持つ。評価情報を座席用シートに複製しないため |
| 班の枠線 | シートの罫線からは読まない。班番号から描く（罫線の引き方の揺れで班の判定が壊れないように） |
| 履歴の順 | 回の番号ではなく日付の順。過去の座席を後から取り込んでも「前回」がずれない |
| 発表の演出 | 「くじ」とは称しない。計算で決めた席を順に見せるだけ |

重みは `src/solver.js` 冒頭の `W` にある。

## 開発

```bash
node apps/seating/scripts/build.mjs          # src → dist
node apps/seating/scripts/build.mjs --check
node apps/seating/tests/test-solver.js       # 必須条件・履歴回避・事前検査
node apps/seating/tests/test-code.js         # シートの値の読み取り
node apps/seating/tests/test-importer.js     # 過去の座席表の対応づけ
NODE_PATH=$(npm root -g) node apps/seating/tests/ui-smoke.mjs   # 画面の通し操作（playwright があれば）
```
