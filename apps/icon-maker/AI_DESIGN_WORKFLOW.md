# AIによるアイコンデザイン再現ワークフロー

## 結論

AIへの依頼は「画面の操作手順」ではなく、**再現URLを伴うデザイン仕様**として返す。これにより、同じ条件を端末・担当者・時期をまたいで再利用できる。

このアプリでAIが扱うデザインは、次の7項目に限定する。

| 項目 | URLパラメータ | 役割 |
|---|---|---|
| アイコン | `icon` | 意味を最短で伝えるピクトグラム |
| 表示名 | `label` | 児童・教員が読む短い語句 |
| 背景色 | `bg` | 意味の補助・系列の識別 |
| アイコン色 | `mode` | `auto`を基本とする可読性の調整 |
| アイコンサイズ | `size` | 視認距離に応じた強弱 |
| 背景形 | `shape` | 用途の種類を示す補助記号 |
| 出力形式 | `layout` | 単体・横長ラベル・正方形カード |

この範囲を超えるイラスト、任意ポーズ、ロゴの模倣は扱わない。必要な場合は、ライセンスを確認したSVGを別途追加する開発タスクにする。

## AIの判断規則

### 1. 依頼を先に構造化する

AIは依頼文から、次を埋める。不明な項目は既定値を使い、その旨を出力に明記する。

| 判断項目 | 既定・判定規則 |
|---|---|
| 読み手 | 児童・保護者・教員のいずれか。未指定なら児童向けとして短い語句を優先 |
| 表示名 | 30文字以内。固有の児童名・出席情報・健康情報は共有URLに入れない |
| アイコン | 意味が1つに定まるものを優先。曖昧なら候補を最大3つ提示 |
| 色 | 用途系列が既にある場合はそれに従う。ない場合のみ下表を初期案にする |
| 背景形 | 下表を使い、装飾目的だけでは増やさない |
| 出力形式 | 単体ボタンは`icon`、掲示の見出しは`horizontal`、カードやタイルは`square-card` |

### 2. 色と背景形を意味に結び付ける

色と形は毎回「きれいに見える」かではなく、同じ用途が同じ見え方になるかで決める。

| 用途 | 初期色 | 初期形 | 使い分け |
|---|---|---|---|
| 通常の学習・案内 | 青・青緑 | 角丸 | 既定。意味を過剰に主張しない |
| 完了・提出・達成 | 緑 | 丸 | 一目で行動完了を確認する |
| 注意・緊急・停止 | 赤・朱 | 盾 | 安全や約束など、誤読を避けたい表示 |
| 区分・分類・単元 | 藍・紫 | 六角 | カテゴリを並べる場面 |
| 表彰・おすすめ・特別 | 黄・橙 | 八星 | 頻用しない。通常の操作と混同させない |
| 行事・運動・動き | 青・緑 | 球体 | 動き・イベントを示す。装飾性が高いため系列内でのみ使う |
| 物・組み立て・環境 | 灰・青緑 | 立方体 / 正面立方体 | 教具、端末、場所など立体物を扱う表示 |

`mode=auto`を既定にする。白・黒の固定は、既存シリーズとの統一など、明確な理由がある場合だけ選ぶ。

### 3. 人物ピクトグラムを優先的に使う場面

人物動作には、一般的な物体アイコンより「誰が何をするか」を短く伝えられる利点がある。運動、移動、姿勢、安全行動にはまず人物カテゴリを検索する。

| 意味 | 内部アイコン名 |
|---|---|
| 走る・かけ足 | `person-run` |
| 全力走 | `person-sprint` |
| 歩く | `person-walk` |
| ストレッチ | `person-stretch` / `person-stretch-side` |
| ヨガ・姿勢 | `person-yoga` |
| 車椅子・バリアフリー | `person-wheelchair` |
| 自転車 | `person-bike` |
| 水泳 | `person-swim` |
| サッカー | `person-football` |
| バスケットボール | `person-basketball` |
| ハンドボール | `person-handball` |
| バレーボール | `person-volleyball` |
| 空手 | `person-karate` |
| スケートボード | `person-skateboard` |
| 友達・ペア・協働 | `people-friends` |

## AIの出力契約

AIは、デザイン依頼に対して次の順番で返す。

1. 用途と読み手を1文で確認する。
2. 採用した7項目を表で示す。
3. 完全な再現URLを1本返す。
4. 判断が割れる場合だけ、最大2案を追加する。
5. 「このアプリでは表現できない要素」があれば、推測で代用せず明記する。

出力例：

```text
用途: 児童が体育の持久走コースを選ぶ案内

| 項目 | 値 |
|---|---|
| icon | person-run |
| label | かけ足 |
| bg | #1565C0 |
| mode | white |
| size | large |
| shape | sphere |
| layout | icon |

設定リンク:
https://script.google.com/macros/s/DEPLOYMENT_ID/exec?icon=person-run&label=%E3%81%8B%E3%81%91%E8%B6%B3&bg=%231565C0&mode=white&size=large&shape=sphere&layout=icon
```

`DEPLOYMENT_ID`は実際のウェブアプリURLに置き換える。AIがデプロイ先URLを受け取っていない場合は、パラメータ部分だけを返し、URLを推測しない。

## 依頼テンプレート

次の形式で依頼すると、AIは判断を安定して再現できる。

```text
アイコンメーカーで作成
用途: （例: 体育の持久走コース案内）
読み手: （児童 / 保護者 / 教員）
表示名: （例: かけ足）
置き場所: （単体ボタン / 横長掲示 / カード）
既存系列: （あれば色・形の規則、なければ「なし」）
避けたい表現: （例: 赤、競争を強く煽る表現）
デプロイURL: （設定リンクまで必要なときだけ）
```

最小依頼は「体育のかけ足用。児童向け、単体」でよい。この場合、AIは未指定項目を既定値として扱い、採用理由を短く添える。

## AIが実際に操作できる場合の手順

1. 依頼を7項目に変換する。
2. デプロイURLへパラメータを付けて開く。
3. アイコン名、表示名、色、形、配置が仕様と一致するか確認する。
4. 必要なら設定リンクをコピーして成果物にする。
5. SVGまたはPNGの保存は、利用者が求めた場合だけ実行する。

AIがブラウザ操作できない場合でも、同じURLを返せば利用者は1回のクリックで再現できる。

## 検証条件

- 表示名は30文字以内
- `icon`は内蔵アイコン名だけを使う
- `bg`は`#RRGGBB`形式
- `shape`は9種類の許可値だけを使う
- URLに共有不要な個人情報を入れない
- 同じ用途の連続したアイコンでは、色・形・出力形式の規則を維持する
- 判断が不確かなときは、見た目だけで1案に決めず、候補と差を提示する
