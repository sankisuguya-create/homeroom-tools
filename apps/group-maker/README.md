# グループ分け

名簿からランダムに組を作り、教室のモニターに大きく映す道具。
`dist/Index.html` を教師用端末のブラウザ（Chrome）で開くだけで動く。サーバも通信も要らない。

## 使い方

1. 初回だけ：右下の「設定」→ スプレッドシートの名簿の範囲（見出しの行ごと）をコピーして貼る →「この名簿にする」。
2. 人数（2〜30人組）を選ぶ。選ぶとすぐ組ができる。
3. 気に入らなければ「組み直す」（スペースキーでも）。押しすぎたら「◀ 前の案に戻す」。
4. 「モニターに出す」→ モニター側の窓を1回押すと全画面。端末とモニターは「拡張」でつなぐ（[教室の時計](../classroom-clock/README.md)と同じ）。

## できること

| 機能 | 内容 |
|---|---|
| 人数 | 2〜30人組（−／＋、よく使う2〜6は1タップ）。割り切れない分は多い組に回す（31人を4人組 → 5人×3組・4人×4組）。指定より少ない組は作らない |
| 表示 | 画面を格子に区切り、1組＝1枠。文字は全部の枠で同じ大きさにし、一番長い名前が収まる最大にする |
| 名前の出し方 | 出席番号／名字だけ／フルネーム。名字は姓と名の間の空白で切る。同じ名字が名簿に2人以上いれば名の1字目を添える（佐藤 健・佐藤 美） |
| 班の名前 | 1班・2班… を出す／出さない |
| 欠席 | 「今日の欠席」で名前を押すと今日だけ外す。翌日は自動で戻る |
| 離す組合せ | 同じ組にしない2人を登録。組み直すたびに守る。人数の都合で守れない時（全員1組など）は画面の下に出す |
| 前回の相手 | 前回と同じ組だった2人を、なるべく別の組にする（入／切）。「前回」は3分より長く映した案 |

設定と今の案はこの端末のブラウザに保存される。読み込み直しても同じ案が出る。

## 直すとき

正本は `src/`（名簿の読み取りは `../class-split/src/paste.js` を共有）。`python3 scripts/build.py` で `dist/Index.html` が出る。
設計の決定と理由は [docs/design.md](docs/design.md)、個人情報の置き場は [docs/pii-map.md](docs/pii-map.md)。

```bash
node --test apps/group-maker/tests/core.test.mjs

```
