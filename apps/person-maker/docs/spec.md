# パーソンメーカー — 設計案 v1（レビュー反映済み）

人のシルエットに属性・服装・色を当てて、校務資料向けの人物画像を作る道具。
**この文書が仕様の正本。** v0 で「未決」とした事項はレビュー回答を反映して §5 に織り込んだ。

設計の物差しは `-` リポジトリの [サイト設計理念](https://github.com/sankisuguya-create/-/blob/main/principles/site-design-philosophy.md) と [低コスト評価軸](https://github.com/sankisuguya-create/-/blob/main/principles/low-cost-evaluation-axes.md) に従う。

---

## 0. 何を作るか / なぜ別ツールか

**作るもの**: 肌・髪・服・小物を部位ごとに色・形を選べる人物画像ジェネレータ。
全身と上半身（バストアップ）を同じデータから出力する。
**複数の人を1つの作業面で並列に持ち、切り替え・複製・削除できる** — 「同職業の5人を素早く作る」使い方を主な型とする。

**使い道（想定）**: 係・当番表の人形、道徳・外国語の登場人物カード、掲示物、名札、
添付例のような「人物カード」（顔＋名前の一覧表示）。

**icon-maker との違い**: icon-maker は「1図形1色」の事物アイコン。
人物は髪・肌・服を別々に塗り分ける必要があるため、**色を層で管理する別モデルが要る**。
出力まわり（コピー／保存／設定リンク）と3列レイアウトは icon-maker の設計・コードを流用する。

## 1. 決めたこと（凍結）

| | 決めたこと |
|---|---|
| 仕組み | 1人分＝レイヤードSVG。部位パーツを下から重ねる |
| 色の単位 | 「部位の役割」ごと（肌・髪・上着・下衣・くつ・小物）。個別パスではなく役割に色を流す |
| 全身/上半身 | 同じSVGデータから出す。上半身は胸ラインで切り出す（viewBox差し替え＋肩フレーム） |
| 編集の始め方 | **プレビューの部位をタップ→その部位の編集になる**（髪をタップ→髪型・髪色） |
| 複数編集 | **人物一覧を常時表示**。並べて作り、選択で編集対象を切り替え、複製・削除できる |
| おまかせ | **未設定の部位だけをランダムに埋める**。確定済みの部位は触らない（§5-E） |
| 名前と属性 | カードに表示するのは**名前のみ**。属性は内部データとして保持し、人物一覧の検索対象にする（§5-A） |
| プリセット | 職業・年代など8件程度。パーツ組合せの定義データで、適用後も部位ごとに上書き可（§5-C） |
| 性別 | パラメータを持たない。髪・服・スカート等を自由に組ませる（§5-D） |
| 体型 | 車椅子を v1 に入れる（Tabler人物を叩き台）。大人・児童・高齢も（§5-B） |
| 出力 | PNG/SVG/JPEG保存・タップでコピー・カード形式・セットJSON・設定リンク（icon-makerと同じ） |
| 保存 | ブラウザ内（localStorage）に自動保存 |
| 図版 | **すべて自前SVG**。素材サイトの画像は使わない（著作権） |
| 配布 | `dist/` = 単一HTML（外部通信・外部ライブラリなし）。ブラウザで開くだけで動く。GASにも置ける |
| 置き場 | `apps/person-maker/`。src/ → `scripts/build.mjs` → dist/、icon-maker と同型 |

### レイヤ構成（下→上）

```
背景(任意/カード) → 体ベース(ポーズ。肌色を含む) → 下衣・くつ(全身のみ)
→ 上着 → 髪 → 表情(目・眉・口・メガネ) → 小物(帽子・名札・持ち物・マスク)
```

各パーツのSVGパスは `data-slot="hair"` のような役割属性を持ち、
選択中の色を役割単位で塗る。パーツ追加は「パス＋slot属性」を足すだけで完結させる（単一真実源）。

### 上半身の出し方

- 人物の図版規格（頭の中心・肩幅・胸ライン）を1箇所に定義し、上半身は同じSVGをそのラインで切る。
- 切り口の下に「肩の丸みフレーム」を敷いて、断面が自然に見えるようにする。
- パーツ図版を全身用・上半身用で二重管理しない — この方式を選んだ理由。

## 2. 複数パーソンの並列編集

icon-maker の「セット」が一覧になるだけでなく、**一覧そのものが編集対象**。

- 人物一覧はサムネイル付きで常時表示。タップで編集対象を切り替える。
- 各人物に **複製**・**削除** の操作（1タップ）。複製は「同職業の5人」の素地：プリセット適用→複製→髪だけ変える、の流れを支える。
- 一覧の上部に検索欄。**名前と内部属性（プリセット名・自由メモ等）で絞り込む**。カード上には出さないが、データとして持つ（§5-A）。
- 選択中の人物は一覧上で枠表示（色だけに頼らない）。
- 並び替え・一括書き出しは v1 の範囲外（後続の未決、§6）。

## 4. 出力・画面

### 出力

| 出力 | 内容 |
|---|---|
| 画像 | PNG/SVG/JPEG。サイズ選択。タップ/右クリックでコピー範囲選択（icon-makerと同じ） |
| カード | 正方形・横長。**人物＋名前のみ**。属性行は載せない（内部データに留める） |
| 一覧JSON | 全人物をJSONで保存・読み込み。複数人体制の正本はこの一覧 |
| 設定リンク | URLパラメータで1人分を再現。人が読める固定形式（`?base=stand&hair=long&tops=suit&tops-color=%23...`） |

### 画面

icon-maker と同じ3列（左＝編集、中央＝プレビュー、右＝一覧と書き出し）。
人物一覧は右列の上部に常駐し、下部に出力操作を置く。

```
┌─────────────┬──────────────┬─────────────┐
│ 部位タブ     │  プレビュー   │ 人物一覧(検索)│
│ 髪 ▾        │  (タップで    │ ┌─┬─┬─┐   │
│ ┌─┬─┬─┐   │   部位選択)   │ │人|人|人|+  │
│ │髪|髪|髪|   │   ┌───┐    │ └─┴─┴─┘   │
│ └─┴─┴─┘   │   │ 人 │    │ 名前・出力   │
│ 髪色 ●●●●○ │   └───┘    │ PNG/SVG等  │
│ 全身/上半身  │[未設定を    │ 設定リンク   │
│            │ おまかせ]   │             │
└─────────────┴──────────────┴─────────────┘
```

## 5. レビュー回答（v0 の未決 → 確定）

| | 質問 | 決定 |
|---|---|---|
| A | カードの文字範囲 | **名前のみ表示。属性は内部保持・検索用** |
| B | 車椅子・特殊体型を v1 に | **入れる** |
| C | プリセット品目 | 提示した8件程度でよい |
| D | 性別の扱い | パラメータなし・自由組合せでよい |
| E | おまかせの範囲 | **「未設定の部位だけおまかせ」**。髪を選んでいれば髪以外をランダムにする |

### 「未設定だけおまかせ」の内部モデル

- 各部位（slot）は「**確定**」または「**未設定**」の状態を持つ。新規人物は全部位が未設定。
- 「おまかせ」を押すと、未設定の部位だけをランダムに選び確定にする。**確定済みの部位は変更しない。**
- 部位を手で選ぶ＝確定。各部位に「未設定に戻す」操作を付け、外せるようにする。
- 未設定の部位がある人物の表示は、描画用の安全な既定値で表示する（内部状態として未設定を持つだけ）。
- 部位ごとの「おまかせ」（その部位だけ再抽選）も付ける — 確定部位を残したまま気に入らない部位だけ回すため。

## 6. 未決（v1 の範囲外・後続）

- 人物一覧の並び替え、複数人の一括書き出し（個別PNG連続保存か、1枚に並べるか）
- 属性メモの項目設計（自由テキスト1行か、プリセット名の自動付与だけか）
- 車椅子のポーズバリエーション

## 7. 実装の進め方

1. `apps/person-maker/` の骨格（icon-makerの build.mjs 流用、単一HTML化）
2. 図版規格（viewBox・部位アンカー・slot属性・上半身クリップ線）を1体「立ち・標準」で作って検証
3. 人物一覧（追加・複製・削除・切替・検索・localStorage自動保存）
4. パーツセットを段階的に増やす（髪→服→小物→ポーズ→車椅子）
5. 出力まわり（コピー/保存/一覧JSON/設定リンク）を icon-maker から移植
6. `tests/` に件数・構文・slot整合の検査を置く
