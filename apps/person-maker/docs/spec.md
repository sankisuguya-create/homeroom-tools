# パーソンメーカー — 設計案 v0（レビュー用）

人のシルエットに属性・服装・色を当てて、校務資料向けの人物画像を作る道具。
**この文書は設計案。確定していない事項は「未決」に分けてある。**

設計の物差しは `-` リポジトリの [サイト設計理念](https://github.com/sankisuguya-create/-/blob/main/principles/site-design-philosophy.md) と [低コスト評価軸](https://github.com/sankisuguya-create/-/blob/main/principles/low-cost-evaluation-axes.md) に従う。

---

## 0. 何を作るか / なぜ別ツールか

**作るもの**: 肌・髪・服・小物を部位ごとに色・形を選べる人物画像ジェネレータ。
全身と上半身（バストアップ）を同じデータから出力できる。

**使い道（想定）**: 係・当番表の人形、道徳・外国語の登場人物カード、掲示物、名札、
添付例のような「人物カード」（顔＋属性の一覧表示）。

**icon-maker との違い**: icon-maker は「1図形1色」の事物アイコン。
人物は髪・肌・服を別々に塗り分ける必要があるため、**色を層で管理する別モデルが要る**。
出力まわり（コピー／保存／セット／設定リンク）と3列レイアウトは icon-maker の設計・コードを流用する。

## 1. 決めたこと（凍結案）

| | 決めたこと |
|---|---|
| 仕組み | 1人分＝レイヤードSVG。部位パーツを下から重ねる |
| 色の単位 | 「部位の役割」ごと（肌・髪・上着・下衣・くつ・小物）。個別パスではなく役割に色を流す |
| 全身/上半身 | 同じSVGデータから出す。上半身は胸ラインで切り出す（viewBox差し替え＋肩フレーム） |
| 編集の始め方 | **プレビューの部位をタップ→その部位の編集になる**（髪をタップ→髪型・髪色） |
| 初期状態 | 「おまかせ」でランダム生成済みの人が表示される。ゼロから選ばせない |
| 属性の与え方 | プリセット（職業・年代など）＝パーツ組合せの定義データ。適用後も部位ごとに上書き可 |
| 出力 | PNG/SVG/JPEG保存・クリックでコピー・カード形式・セットJSON・設定リンク（icon-makerと同じ） |
| 保存 | ブラウザ内（localStorage）に自動保存 |
| 図版 | **すべて自前SVG**。素材サイトの画像は使わない（著作権）。Tabler人物（MIT）はポーズの叩き台まで |
| 配布 | `dist/` = 単一HTML（外部通信・外部ライブラリなし）。ブラウザで開くだけで動く。GASにも置ける |
| 置き場 | `apps/person-maker/`。src/ → `scripts/build.mjs` → dist/、icon-maker と同型 |

### レイヤ構成（下→上）

```
背景(任意/カード) → 体ベース(ポーズ。肌色を含む) → 下衣・くつ(全身のみ)
→ 上着 → 髪 → 表情(目・眉・口・メガネ) → 小物(帽子・名札・持ち物・マスク)
```

各パーツのSVGパスは `data-slot="hair"` のような役割属性を持ち、
選択中の色を役割単位で塗る。パーツ追加は「パス＋slot属性」を足すだけで完結させる（単一真実源）。

### 上半身の出し方

- 人物の図版規格（頭の中心・肩幅・胸ライン）を1箇所に定義し、上半身は同じSVGをそのラインで切る。
- 切り口の下に「肩の丸みフレーム」を敷いて、断面が自然に見えるようにする。
- パーツ図版を全身用・上半身用で二重管理しない — これがこの方式を選んだ理由。

### 操作コストを下げる決め（設計理念との対応）

- **部位タップ編集**: 部位名をメニューから探す操作（Hick則の探索コスト）を消す。対象は大きく（児童タッチ精度も考慮）。
- **おまかせ生成**: 全パーツをランダムに組んで表示 → 気に入らない部位だけ直す。「機械が決めて、安く直せる」形。
- **プリセット**: 「教師」「児童」「医師」「調理員」などを選ぶと服装＋小物が一度に入る。手で9部位選ぶ操作列を1タップに圧縮。
- **元に戻す**: 直前の変更を1タップで戻せる。
- パレットはプリセット級ではなく「役割ごとの少数スウォッチ＋自由色」。同時提示の選択肢を絞る。

### 色の考え方

- ここでの色は**識別のための色分けではなく装飾** — color-coding スキルの「識別色の上限」の対象外。
- 肌色・髪色は実在範囲で厳選した固定パレット（肌4〜6、髪5〜7）。服はスウォッチ＋自由色。
- 人物の色で班・グループを分ける利用はあり得るが、その場合「色だけに頼らない」は資料側の責任。
  READMEに1行だけ原則を書く。ツール内では色数を強制しない。
- 人物カード上に状態・正誤を載せる場合は tokens.css の系統を使う。

## 2. パーツ一覧（v1の範囲案）

| 層 | 品目案 |
|---|---|
| 体ベース | 立ち・歩く・手を上げる・座る・走る ／ 体型: 大人・児童（小柄）・高齢（背屈み） |
| 髪 | なし・短髪・マッシュ・おかっぱ・ロング・ポニーテール・おだんご・ツインテール |
| 表情 | 標準・笑顔・真顔・困り ＋ メガネ（丸/角）・マスク（任意レイヤ） |
| 上着 | Tシャツ・シャツ・ブラウス・スーツ・セーター・体操服・白衣・エプロン・作業着 |
| 下衣・くつ | ズボン・スカート・短パン ＋ くつ・上履き・長靴 |
| 小物 | 名札・ネクタイ・リボン・帽子（制帽/給食帽/ヘルメット）・持ち物（本・笛・指し棒等） |
| プリセット | 教師・児童・医師・調理員・警察・店員・高齢者 …（上記パーツの組合せ定義） |

## 3. 出力案

| 出力 | 内容 |
|---|---|
| 画像 | PNG/SVG/JPEG。サイズ選択。タップ/右クリックでコピー範囲選択（icon-makerと同じ） |
| カード | 正方形・横長。人物＋名前＋属性行（添付の人物カード例の形） |
| セット | 複数の人をJSONで保存・読み込み。係表やカード一式をまとめて作る |
| 設定リンク | URLパラメータで1人分を再現。人が読める固定形式（`?base=stand&hair=long&tops=suit&tops-color=%23...`） |

## 4. 画面案

icon-maker と同じ3列（左＝選択、中央＝プレビュー、右＝書き出し）。
違いは左列が「アイコン一覧」ではなく「部位タブ（髪/服/小物…）＋部位内の選択肢グリッド」になる点。
中央プレビューでは部位タップがそのまま編集対象の選択になる（選択中の部位に枠を出す）。

```
┌─────────────┬──────────────┬─────────────┐
│ 部位タブ     │  プレビュー   │ 名前・カード  │
│ 髪 ▾        │  (タップで    │ 出力形式     │
│ ┌─┬─┬─┐   │   部位選択)   │ 画像サイズ   │
│ │髪|髪|髪|   │   ┌───┐    │ PNG/SVG保存 │
│ └─┴─┴─┘   │   │ 人 │    │ セットJSON  │
│ 髪色 ●●●●○ │   └───┘    │ 設定リンク   │
│ 全身/上半身  │ [おまかせ]  │             │
└─────────────┴──────────────┴─────────────┘
```

## 5. 未決（実装前に決めたい）

| | 未決事項 | 案 |
|---|---|---|
| A | カードの文字は「名前のみ」か「名前＋属性行」まで入れるか | 名前＋属性2行（添付例の形）に寄せる |
| B | 車椅子・ベビーなど特殊体型をv1に入れるか | 車椅子はTabler参考にv1で入れたい |
| C | 職業プリセットの品目と粒度 | 上表の8件程度で始める |
| D | 性別の扱い | 性別パラメータは持たない。髪・服・スカートを自由に組ませる |
| E | 「おまかせ」のランダム対象（配色までランダムか） | パーツ＋配色ともランダム、肌・髪は実在範囲から |

## 6. 実装の進め方（案）

1. `apps/person-maker/` の骨格（icon-makerの build.mjs 流用、単一HTML化）
2. 図版規格（viewBox・部位アンカー・slot属性）を1体「立ち・標準」で作って検証
3. パーツセットを段階的に増やす（髪→服→小物→ポーズ）
4. 出力まわり（コピー/保存/セット/リンク）を icon-maker から移植
5. `tests/` に件数・構文・slot整合の検査を置く
