# 回収チェック表 — 仕様

児童に配ったもの・集めたもの（同意書・集金・連絡帳・しおりの回収など）を、
**名簿×品目の表**で追う道具。`dist/Index.html` をブラウザで開くだけで動く。

**この文書が仕様の正本。** 実装で迷ったらここに戻る。

---

## 0. 何を解いているか

回収物は「配った人へ渡して、集まった数を数える」仕事が毎週ある。
紙の名簿に手で線を引く方法の弱点は、**何が誰の分でいくつ残っているかが、
ひと目に出ない**こと。数えるのはそのたびに指を折る作業になる。

だからこの道具は、**名簿の行と品目の列が交わるところをまるごとチェック欄にする**。
クリックで印が付き、列ごとに「収まった数/出すべき数」が自動で出る。
紙に刷って机の上に置いても使える。

## 1. 決めたこと

| | |
|---|---|
| 単位 | 児童の行×品目の列。1マスは1回の回収 |
| 印の4状態 | `空欄`（まだ）→ `✓`（収まった）→ `済`（中身・金額まで確かめた）→ `−`（対象外・免除）→ `空欄`。クリックで回る |
| 数え方 | 列の下に「収 n / 対象 m」、その下に「残・未確・外」を出す。対象外は分母から外し、「済」は収に含める |
| 提出率 | バーに「収まった数 ÷ 出すべき数」の合計を％で出す |
| 残の目安 | 行の右端にその児童の未提出数を出す。多い児童が目立つ |
| まとめて入力 | 「番号でまとめて」は出席番号を読み上げて打つだけで印を一括で付ける。品目ごとの全員✓・全消しもある |
| 未提出の一覧 | 品目ごとに残っている児童を抜き出す。番号だけの表示に切り替えて掲示用に刷れる。表とは別に一覧だけ印刷できる |
| 締め切り | 品目ごとに日付を付けられる。過ぎて残がある列は見出しが赤くなる。刷り物にも締切日が出る |
| 番号の並び | 番号欄の ⇅ で出席番号順に並べ替える。転入・順番崩れのあとに使う |
| 名を隠す | 氏名を一時的に伏せる。投影・画面共有のときに使う（印と番号は見えたまま） |
| 名簿 | スプレッドシートの名簿表を範囲コピーして貼り付ける。列の役割（番号/氏名/使わない）は貼ったあとに選ぶ |
| 名簿の更新 | 「置き換え」は番号＋氏名が一致する児童の印を引き継ぐ。「追加」は末尾に足す |
| 品目 | 列は自由に足す・名前を変える・並べ替える・消せる |
| 保存 | ブラウザ内（localStorage）。打つたび自動 |
| 持ち運び | JSONの書き出し・読み込み。私用PCと校務PCの間はこれで渡す |
| 紙 | A4。品目が少なければ縦、増えれば横。印は刷り出したときの状態が写る。未提出一覧は一覧だけ別に刷れる |

## 2. 決めなかったこと

**表は1枚だけ持つ。** 1つのブラウザに1枚。学期や用途で分けたいときはJSONを書き出して作り直す。
名簿だけ残して品目を入れ替える運用で学年の1年を回せるので、表の一覧画面は足さない。

**サーバに置かない。** GAS もスプレッドシートの API も使わない。
名簿の取り込みはコピー＆ペーストだけで、ファイルやネットワークへは一切出さない（4節）。

**児童の顔・連絡先・備考は持たない。** 番号と氏名と印だけ。要録や連絡票にはならない。

**印刷レイアウトを細かく決めない。** 余白・罫線は既定の組み合わせだけ。
縦横は品目数で自動にして、操作を増やさない。

## 3. 名簿の取り込み

名簿表（Google スプレッドシート等）の範囲をコピーして、
画面の「名簿を取り込む」にある貼り付け欄へ貼る。

| 決まり | 内容 |
|---|---|
| 区切り | タブ区切りを基本とし、カンマ区切りも読む |
| 見出し行 | 1行目が「番号/氏名/名前/出席」などの見出し語を含むときは名簿に入れない（自動判定。切り替えられる） |
| 列の役割 | 列ごとに `番号 / 氏名 / 使わない` を選ぶ。数字が多い列を番号、それ以外の最も氏名らしい列を氏名として初期推測する |
| 番号なし | 氏名列だけでも取り込める。その場合は上から連番を振る |
| 全角数字 | `１２３` は半角に直して読む |
| 置き換え | 番号＋氏名が一致する児童は同じ人とみなし、印を引き継ぐ。一致しない児童は名簿ごと消える |
| 追加 | 現在の名簿の末尾に足す（重複は貼ったとおりに入る） |

取り込み前に何行かのプレビューを見せ、列の役割を確かめてから適用する。
貼った文字はその場でしか使わず、名簿として確定した分だけが保存される。

## 4. 個人情報

児童の氏名を扱う道具なので、**外部との通信はしない**。

- ウェブフォントも外部からは読まない（端末内のフォントだけで出る）
- 名簿・印はこの端末のブラウザの中にだけ保存される
- 他の端末へ渡すときは JSON を書き出して、使う人が自分で運ぶ
- 作ったJSON・刷った表は名簿なので、紛失・公開の扱いは学校の名簿と同じにする

このリポジトリは公開設定なので、**名簿を入れたJSONはコミットしない**。

## 5. 直すとき

元は `src/Index.html`。`python3 scripts/build.py` で `dist/Index.html` が出る。
色トークンは `shared/ui/tokens.css` から `@include` で入るので、色の値はこの道具の中に書かない。
`dist/Index.html` を直接編集しても次のビルドで消える。
