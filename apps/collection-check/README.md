# 回収チェック表

同意書・集金・連絡帳など「配って、集めて、数える」仕事を、
**名簿×品目の表**にして追う道具。
`dist/Index.html` をブラウザで開くだけで動く。サーバもビルドも要らない。

## 何を解いているか

紙の名簿に手で線を引くやり方は、**何が誰の分でいくつ残っているかが
ひと目に出ない**。数えるたびに指を折る作業になる。

この道具は、名簿の行と品目の列が交わるところをまるごとチェック欄にする。
マスをクリックすると 空欄 → **✓**（収まった）→ **−**（対象外）→ 空欄 と印が回り、
列の下に「収まった数／出すべき数」、行の右にその児童の残数が自動で出る。

## 決めたこと

| | |
|---|---|
| 名簿 | スプレッドシートの名簿表を範囲コピーして貼り付ける。列の役割（番号・氏名・使わない）は貼ったあとに選ぶ |
| 名簿の更新 | 「置き換え」は番号＋氏名が一致する児童の印を引き継ぐ。「追加」は末尾に足す |
| 品目 | 列は自由に足す・名前を変える・並べ替える・消せる |
| 保存 | ブラウザ内（localStorage）。打つたび自動 |
| 持ち運び | JSONの書き出し・読み込み。私用PCと校務PCの間はこれで渡す |
| 紙 | A4。品目が少なければ縦、増えれば横 |

詳しい決まりは [docs/spec.md](docs/spec.md) が正本。

## 決めなかったこと

**表は1枚だけ持つ。** 名簿だけ残して品目を入れ替える運用で1年を回せるので、一覧画面は足さない。

**サーバに置かない。** GAS もスプレッドシートの API も使わない。

## 個人情報

児童の氏名を扱うので、**外部との通信はしない**。
ウェブフォントも読まず、氏名・印はこの端末のブラウザの中にだけ保存される。
別端末へ渡すときは JSON を書き出して自分で運ぶ。

**名簿を入れたJSONはコミットしない**（このリポジトリは公開）。
刷った表も名簿と同じ扱いで管理する。

## 直すとき

元は `src/Index.html`。`python3 scripts/build.py` で `dist/Index.html` が出る。
色トークンは [`../../shared/ui/tokens.css`](../../shared/ui/tokens.css) から `@include` で入るので、色の値はこの道具の中に書かない。
`dist/Index.html` を直接編集しても次のビルドで消える。
