# スライド1枚目まとめ印刷

Classroomで提出させたGoogleスライドの**1枚目だけ**を、課題フォルダから一括で取り出して印刷するGASウェブアプリ。Classroom APIは使わない（Driveの課題フォルダを読む）。

## 設置（1回）
1. script.google.com で新規プロジェクト。`コード.gs` を `src/Code.gs` の中身に置き換え、HTMLファイル `index` を作って `src/index.html` を貼る。
2. 「サービス ＋」で **Google Slides API** を追加。
3. 学校アカウント（@edu.nishi.or.jp）で作り、デプロイ → ウェブアプリ。実行ユーザー：**アクセスしているユーザー**／アクセス：ドメイン内の全員。
   - 「自分として実行」にしない：他の教員の課題フォルダは作成者に共有されておらず読めない。かつURLを知る人が作成者のDriveのスライドを取り出せてしまう。
   - 他の教員はURLを開き初回に許可するだけ（Slides APIの追加は不要）。改修時は同じデプロイを「新しいバージョン」で更新し、URLを変えない。

ビルド不要。`src/` をそのまま貼る（`dist/` は無い）。

## 使い方
課題フォルダ（Drive「Classroom」→授業→課題）のURLを貼る →「読み込む」→「印刷」（A4・倍率既定・背景のグラフィックON）。
