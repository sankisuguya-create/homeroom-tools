# 設計の決定

| 決定 | 理由 |
|---|---|
| 1枚目を**サムネイル画像**（Slides API `getThumbnail` LARGE＝幅1600px）で取得する | `appendSlide` でスライドを複製する方式は、テーマ・フォントの合流でレイアウトが崩れ実用にならなかった（実機確認 2026-11-18） |
| 1スライド＝1ページ、ページ向きをスライドの縦横比で切替（CSS 名前付きページ `@page land/port`） | 縦長スライドを横長スライドに入れ縦用紙に刷ると二重に縮小された（実機確認）。名前付きページは Chrome/Edge 前提（未確認） |
| 画像は `contentUrl` を `<img>` に直接入れる | サーバーで取得して埋め込むより速い。URLの有効期限は約30分なので、読み込み後すぐ印刷する前提 |
| 1件ずつ画面から `apiThumb` を呼ぶ | GASの6分上限を回避し、進捗を出すため。429等は最大4回待って再試行 |
| 並び順：所有者メール（児童＝数字8桁）→無ければファイル名 | 出席番号順を想定（採番との一致は未確認） |
| 名前：ファイル名の「 - 」より前 | Classroomの既定命名「氏名 - 課題名」 |
| 実行ユーザー＝アクセスしているユーザー | 教師自身のDrive権限で課題フォルダを読むため |

個人情報：児童名（ファイル名）を画面・印刷に表示するのみ。保存はしない。

## 画面（2026-11-18 改訂）
- 縦1列の2ステップ（①URLを貼る →②印刷）。②は読み込み完了まで薄く無効化し、次にすべきことを1つに絞る。
- URLを**貼った瞬間に自動で読み込む**（Enter・「読み込む」ボタンも可）。操作1回減。
- 進捗はバーと「n / 全数」。失敗は赤枠で一覧に残し、印刷からは除外。
- 「名前も印刷する」はスイッチ（即反映）。フォルダの場所の説明は既定で閉じた折りたたみ。
- 一覧は小さいサムネイルの格子（確認用）。印刷時のみ1枚＝1ページに展開。
- ui-layout 検査：不合格0（注意2＝中央寄せの auto 余白で、意図どおり）。初見の教員での観察は未実施。

## 改訂（2026-11-18 その2）
- 印刷するスライドをセグメントで選ぶ：1枚目／2枚目／すべて／◯枚目（番号入力）。読み込み後に切り替えると自動で読み直す。該当の番号が無いファイルは赤枠「n枚目がありません（全m枚）」。
- 一覧の画像を押すと「印刷しない」に切り替わる（青枠＝印刷、薄い＝除外）。印刷枚数を常に表示し、0枚なら印刷ボタンを無効化。
- URL：`…/folders/ID`（u/0/ や ?usp= 付きも可）、`?id=ID`、ID単体のいずれも受け付ける。
- 「フォルダはどこ？」の説明は削除。
- サーバー関数を `apiThumb` → `apiThumbs(fileId, which)` に変更。**Code.gs と index.html を両方貼り直す**（片方だけだと「サーバーに『apiThumbs』がありません」と出る）。
- 「すべて」は1人数枚×人数ぶん画像を取るので時間がかかる（1枚約1〜2秒の見込み、未実測）。
- 模擬サーバーでの動作確認済み（選択切替・欠番・除外・URL形式）。GAS実機は未確認。
