# 設計の決定

| 決定 | 理由 |
|---|---|
| 1枚目を**サムネイル画像**（Slides API `getThumbnail` LARGE＝幅1600px）で取得する | `appendSlide` でスライドを複製する方式は、テーマ・フォントの合流でレイアウトが崩れ実用にならなかった（実機確認 2026-11-18） |
| 1スライド＝1ページ、ページ向きをスライドの縦横比で切替（CSS 名前付きページ `@page land/port`） | 縦長スライドを横長スライドに入れ縦用紙に刷ると二重に縮小された（実機確認）。名前付きページは Chrome/Edge 前提（未確認） |
| 画像は `contentUrl` を `<img>` に直接入れる | サーバーで取得して埋め込むより速い。URLの有効期限は約30分なので、読み込み後すぐ印刷する前提 |
| 1件ずつ画面から `apiThumb` を呼ぶ | GASの6分上限を回避し、進捗を出すため。429等は最大4回待って再試行 |
| 並び順：所有者メール（児童＝数字8桁）→無ければファイル名 | 出席番号順を想定（採番との一致は未確認） |
| 名前：ファイル名の「 - 」より前 | Classroomの既定命名「氏名 - 課題名」 |
| 実行ユーザー＝アクセスしているユーザー | 教師自身のDrive権限で課題フォルダを読むため |

個人情報：児童名（ファイル名）を画面・印刷に表示するのみ。保存はしない。

## 画面（2026-11-18 改訂）
- 縦1列の2ステップ（①URLを貼る →②印刷）。②は読み込み完了まで薄く無効化し、次にすべきことを1つに絞る。
- URLを**貼った瞬間に自動で読み込む**（Enter・「読み込む」ボタンも可）。操作1回減。
- 進捗はバーと「n / 全数」。失敗は赤枠で一覧に残し、印刷からは除外。
- 「名前も印刷する」はスイッチ（即反映）。フォルダの場所の説明は既定で閉じた折りたたみ。
- 一覧は小さいサムネイルの格子（確認用）。印刷時のみ1枚＝1ページに展開。
- ui-layout 検査：不合格0（注意2＝中央寄せの auto 余白で、意図どおり）。初見の教員での観察は未実施。

## 改訂（2026-11-18 その2）
- 印刷するスライドをセグメントで選ぶ：1枚目／2枚目／すべて／◯枚目（番号入力）。読み込み後に切り替えると自動で読み直す。該当の番号が無いファイルは赤枠「n枚目がありません（全m枚）」。
- 一覧の画像を押すと「印刷しない」に切り替わる（青枠＝印刷、薄い＝除外）。印刷枚数を常に表示し、0枚なら印刷ボタンを無効化。
- URL：`…/folders/ID`（u/0/ や ?usp= 付きも可）、`?id=ID`、ID単体のいずれも受け付ける。
- 「フォルダはどこ？」の説明は削除。
- サーバー関数を `apiThumb` → `apiThumbs(fileId, which)` に変更。**Code.gs と index.html を両方貼り直す**（片方だけだと「サーバーに『apiThumbs』がありません」と出る）。
- 「すべて」は1人数枚×人数ぶん画像を取るので時間がかかる（1枚約1〜2秒の見込み、未実測）。
- 模擬サーバーでの動作確認済み（選択切替・欠番・除外・URL形式）。GAS実機は未確認。

## 改訂（2026-11-18 その3）印刷の設定
- ②に「用紙（A4/B5/A3/B4）」「1ページに（1/2/4/6枚）」「余白（せまい5mm/ふつう12mm/広い30mm）」のセグメントを追加。選択は端末ごとに localStorage で記憶。B5・B4はJIS。
- 印刷時に `#sheets` へ用紙1枚ずつの格子を組み立て、`@page L/P` を動的に書く。用紙の向きと並べ方はスライドの縦横で決める（縦長：2枚→横用紙に左右、4枚→縦用紙2×2、6枚→横用紙3×2。横長はその逆）。縦長と横長が混ざる時は、向きが変わる所で新しいページにする。
- Chromium（Playwright）でPDFを出力し、ページ数と用紙寸法が設定どおりになることを確認（A4縦7枚／A4・4枚→2頁／B4横364×257mm・6枚→2頁／A3横・2枚→4頁）。実機のプリンタでの拡大縮小・余白は未確認。印刷画面の「倍率」は既定（100%）のままにする前提。

## 改訂（2026-11-18 その4）使い勝手レビューの反映
- **並び順**：所有者アドレス順を廃止。提出すると所有者が教師へ移る（返却で児童に戻る。Google Assignments ヘルプ）ため、提出済みが順不同になっていた。ファイル名の氏名部分を `localeCompare('ja',{numeric:true})` で並べる（名前の頭に番号があれば番号順）。出席番号との一致は名前の付け方次第（未確認）。
- **元ファイル（雛形）**：名前に「 - 」が無いものを元ファイルとみなし、末尾に並べて既定で「印刷しない」にする（推定。Classroomの命名「氏名 - 元ファイル名」に依存）。
- **提出済の印**：所有者＝操作している教師なら「提出済」。返却後は児童に戻るので目安。
- **用紙の注意**：A4以外を選ぶと「印刷画面の用紙サイズも◯◯に」と表示。
- **時間**：画像取得は1人毎分60回まで（Slides API 公式の上限）。進捗に残り時間の目安を表示。
- **メモリ**：「すべて」は MEDIUM（幅800px）で取得。1枚目等は LARGE（1600px）。
- **古い画像**：読み込みから20分以上たって印刷を押すと、選択（印刷しない）を保ったまま読み直す。thumbnail の URL の有効期限は公式記載が見つからないため安全側。
- **選択**：各画像に ✓、「全部入れる／全部外す」。
- **履歴**：読み込んだフォルダを3件まで覚え、フォルダ名のボタンで再読込（専科の学級切替用）。localStorage に URL とフォルダ名だけを保存。
- サーバー：`apiThumbs(fileId, which, size)`、`apiListFiles` が `template` `mine` を返す。**Code.gs・index.html を両方貼り直す。**

## 改訂（2026-11-19）印刷の取りこぼし対策・PDFで保存
- **✓を外したものが印刷される（報告）への対策**：印刷用の紙面を「印刷」ボタンを押した時だけ作っていた。Ctrl+P・ブラウザのメニューからの印刷や、GASの外枠ページ側の印刷では、ボタン押下時の古い紙面（または beforeprint が子の iframe に届かない場合）が使われうる。✓・設定を変えるたびに紙面を作り直す形に変更。報告の再現はできておらず、原因の特定は未了（実機で再確認が要る）。
- **PDFで保存**：✓の付いたものだけを、印刷と同じ並べ方（用紙・枚数・余白・名前）でPDFにして保存。各ページを 150dpi の canvas に描き JPEG で jsPDF（cdnjs 2.5.1）に貼る。Googleのサムネイル画像はそのままでは canvas に描けないため、サーバー `apiImage(url)` で取り直して data URL にする（googleusercontent.com のURLだけ受け付ける）。
- 未確認：GASウェブアプリの枠内からのダウンロードが通るか、学校のネットワークで cdnjs が開けるか。
