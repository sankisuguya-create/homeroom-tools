# 机の配置図 — 設計の理由

## 目的と頻度
- 映すのは毎時間（教師が1タップ）。作るのは学期に数回。→ 映す操作は「カードを押す」だけにし、編集は別画面に分けて手間を許す。

## 図の向き
- 上から見た図は「児童がすわる がわ」を画面の下にする。モニターを見る児童の向きと一致させ、頭の中での回転を要らなくする。
- 横から見た図は、その面に立って見たとおりに描き（前から見た図は左右が逆に見える）、上から見た図のその面の側に置く。どの面の図かを位置で示すため。
- 横から見た図は 0.6 倍で描く。主に伝えるのは机の上の配置で、横は「どのフックに何を掛けるか」だけ伝わればよい。脚は掛けた物のすぐ下で切る（破線）。
- 掛ける物が1つもない配置では横から見た図を出さず、上から見た図を大きくする。

## 名前
- 既定で名前を出さないのは利用者の指定。絵で分かる物に文字を足すと、児童が読む量が増える。
- 吹き出しは机の外の余白に置き、引き出し線の先に点を打つ。机の上に重ねると配置そのものが隠れる。
- 同じ用具でも活動によって名前が要る・要らないが違うので、名前を出すかは「置いた物ごと」に持つ。
- 4人表示で全部の机に名前を出すと同じ名前が4つ並ぶので、手前左の机だけに出す。

## 色
- 用具の色は実物らしさのための描写で、区別の手がかりは形と名前。色で意味を伝える所（正誤など）はない。

## 4人グループ
- 手前2台は1台表示と同じ向き、奥2台は180°回して前の辺どうしを合わせる。
- 机どうしがくっつく内がわのフックには物を掛けられない。実際には外がわへ掛け替えるので、図でも外がわに寄せて描く。

## 保存
- 名簿などの個人情報を持たないので、サーバ（GAS）を使わずブラウザ保存にした。端末をまたぐときは JSON の書き出し・読み込みを使う。
- 校内で配置を共有したくなったら、保存の層（load/save）を GAS に差し替える。

## 置き場所のグリッド
- 自由な位置にすると、教師に指先での細かい操作を求めることになる。物の中心は、天板を等分した線の交点と、机の外に「あらい」1目分（約108×113mm）広げた交点にだけ置ける。外の交点があるので、本が半分だけ机に乗るような配置も交点に揃う。はみ出す分は各段でも「あらい」1目分（＝段ごとの整数目）に統一しているので、細かい段は粗い段の交点をすべて含む関係が保たれる。
- 細かさは3段：あらい 6×4（約108×113mm）／ふつう 12×8（約54×56mm、初期設定）／こまかい 24×16（約27×28mm）。
  分割数を2倍ずつにしているので、細かい段は粗い段の交点をすべて含む。段を切り替えても、置いた物はずれない。
- 動かし方は3つ：ドラッグ（いちばん近い交点に吸着）、物を選んでから広げた範囲内の空いた所を押す、矢印キーで1目ずつ。
- 物が机からはみ出すのは許す。教科書にノートを重ねるなど、実際の机でも起きるため。上から見た図の描画範囲にはみ出した分も含める。

## 用具の絵
- 「形＋見分けるための印1つ」までに減らす。モニターを遠くから見るので、細かい模様は灰色のかたまりにしか見えず、読む量だけ増える。
- ノートの表紙は方眼ノート（学習帳）に合わせる：色の地、左下の方眼の面、下の名前欄。表紙の色は5色から選べる（標準では算数が青、国語が桃）。
- ノートは B5（179×252）／A4（210×297）、教科書は B5（182×257）／A4（210×297）を、置いた物ごとに選べる。
- 教科書・ノートの開き方は2つ：「ひらく」（180°、左右のページが見えて幅2倍）と「360°」（表紙をうしろへまげた形。見えるのは1枚のページだけで、机での大きさは閉じた形と同じ）。360°は教科書・ノートを重ねて置いた図で、下の物と同じ幅で描ける。360°の絵は、綴じがわの長辺がまげられた紙と表紙の筒に丸まる（利用者の写真で確認。筒は長辺のはしまで寄せ、両はしが長辺の両端にかぶる。巻き口の輪は上はしだけ（下はしは単純な半円）、ページは筒の下にもぐる）。表紙はうしろに隠れるので、四辺に表紙色の縁は出さず、見える面はページ1枚。筒が左にある「360°」のほか、左右反対の「360°右」（筒が右の長辺）も選べる。
- ノート・連絡帳・ファイルの表紙には「ノート」「れんらく」「ファイル」と書く。左右反転で絵を鏡にしても、文字だけは裏返さない（`MIRROR`）。
- 絵の具セットは画材セットの箱型バッグ（幅325×奥行140×高さ140）に合わせる。上から見ると2本の持ち手の帯と手前のベルト、横から見ると箱に持ち手とベルトの金具。色は黒・紺・ラベンダー・灰・青の5色。
- 表紙の色は、色見本のボタンを1回押して選ぶ（順送りより押す回数が少ない）。
- フックに掛けた物（絵の具セットを含む）の色は、今は選べない。掛けた物ごとに色を持たせる必要がある。
- のり・墨汁・パソコン（開いた形）は、やや斜め（手前の上）から見た絵にする。真上からだと、のり・墨汁はただの丸、開いたパソコンは画面が細い帯にしか見えず、何の物か分からないため。図の大きさは見た目の高さに合わせて、置いた場所の寸法より縦に長くしている。
- フックは左右の面の前後中央（hookY = 225）。上から見た図にはフックの印を描かない（天板の下にあって上からは見えず、置き方の情報にならないため）。
- タブレットは児童の端末 ASUS Chromebook CZ11 Flip（CZ1104F）に合わせる：ミネラルグレーの本体、一周する濃い色のゴムのバンパー、黒い画面の縁（[ASUS](https://www.asus.com/us/laptops/for-students/chromebook/asus-chromebook-cz11-flip-cz1104f/)）。
  形は4つ：とじる（ふたの左下に黄と白の横長シール）・タブレット（画面を上にして反対側へ畳む）は真上から、ひらく（キーボードの面は奥が少しだけせまい台形）・山がた（下の辺は他の形と同じ幅、傾きは「ひらく」のキーボードと同じ。枠・黒い縁・画面は同じ傾きでそろえ、角は丸める。左右に後ろの脚の縁が角の丸い三角でのぞく）は手前の上から見た絵。編集画面では状態をボタンで直接選ぶ。
- 見せる画面の「横から見た図」ボタンで、真上からの図だけにできる（保存される）。4人表示では横から見た図をもともと出さないので押せない。
- 「大きく映す」：全画面にし、操作ボタンと「しまう物」を隠して、上に「机の上をこの形にしてね」（ふりがな付き）、残りを真上からの図に使う。メッセージは縮まない帯（背景不透明・最前面・左右は×ボタン分の余白）として図と分け、図のラベルがあっても被らないようにする。4人表示でも使える。やめるのは右上の×・Esc・全画面の解除。その場かぎりで保存しない。
- プリント：判型は B5（182×257）・A4（210×297）・B4（257×364）・A3（297×420）。識別のための文字（16字まで）を置いた物ごとに書ける。文字は紙の幅に収まる大きさで上寄りに描き、左右反転しても裏返さない。
- 標準の配置に「算数（図形）」（ノート・分度器・三角定規2枚・コンパス・鉛筆・消しゴム）と「プリント」（B4のプリント「漢字①」・鉛筆・赤鉛筆・消しゴム）を加えた。
