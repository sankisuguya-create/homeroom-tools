# 机の配置図 — 設計の理由

## 目的と頻度
- 映すのは毎時間（教師が1タップ）。作るのは学期に数回。→ 映す操作は「カードを押す」だけにし、編集は別画面に分けて手間を許す。

## 図の向き
- 上から見た図は「児童がすわる がわ」を画面の下にする。モニターを見る児童の向きと一致させ、頭の中での回転を要らなくする。
- 横から見た図は、その面に立って見たとおりに描き（前から見た図は左右が逆に見える）、上から見た図のその面の側に置く。どの面の図かを位置で示すため。
- 横から見た図は 0.6 倍で描く。主に伝えるのは机の上の配置で、横は「どのフックに何を掛けるか」だけ伝わればよい。脚は掛けた物のすぐ下で切る（破線）。
- 掛ける物が1つもない配置では横から見た図を出さず、上から見た図を大きくする。

## 名前
- 既定で名前を出さないのは利用者の指定。絵で分かる物に文字を足すと、児童が読む量が増える。
- 吹き出しは机の外の余白に置き、引き出し線の先に点を打つ。机の上に重ねると配置そのものが隠れる。
- 同じ用具でも活動によって名前が要る・要らないが違うので、名前を出すかは「置いた物ごと」に持つ。
- 4人表示で全部の机に名前を出すと同じ名前が4つ並ぶので、手前左の机だけに出す。

## 色
- 用具の色は実物らしさのための描写で、区別の手がかりは形と名前。色で意味を伝える所（正誤など）はない。

## 4人グループ
- 手前2台は1台表示と同じ向き、奥2台は180°回して前の辺どうしを合わせる。
- 机どうしがくっつく内がわのフックには物を掛けられない。実際には外がわへ掛け替えるので、図でも外がわに寄せて描く。

## 保存
- 名簿などの個人情報を持たないので、サーバ（GAS）を使わずブラウザ保存にした。端末をまたぐときは JSON の書き出し・読み込みを使う。
- 校内で配置を共有したくなったら、保存の層（load/save）を GAS に差し替える。
