# 机の配置図

授業や活動の前に、**机の上に何をどこへ置くか**・**フックに何を掛けるか**・**何をしまうか**を
教室の大画面モニターに映して見せる道具。
`dist/Index.html` をブラウザで開くだけで動く。サーバも名簿も使わない。

## 使い方

1. 活動カード（算数・国語・習字・絵の具・パソコン・テスト…）を押す → 全画面の配置図が出る
2. 上のボタンで切り替える：`1人／4人`・`左右反転`・`いす`・`ふりがな`・`⛶`（全画面）
3. キーボードの ← → で次の活動へ
4. カードの「なおす」で配置を編集する。動かした時点で保存される

## 画面

| 画面 | 誰が・どのくらい | 内容 |
|---|---|---|
| えらぶ | 教師・毎時間 | 活動カード。最後に映した順に並ぶ |
| 見せる | 児童が見る | 中央に上から見た図。掛ける物があるときだけ、その面の側に「ひだりから／みぎから／こくばんがわから／うしろから」の図。右端に「しまう物」 |
| なおす | 教師・学期に数回 | 机の上へドラッグ。選んだ物は「ひらく／とじる」「回す」「名前を出す」「いちばん上へ」「けす」。フックと「しまう物」はパレットから足す |

## 決めたこと

| | |
|---|---|
| 机の形 | 天板は平ら、物入れは児童がわに開く、フックは左右両側の中央（実物の写真から） |
| 名前 | 初期状態では出さない。「名前を出す」をオンにした物だけ吹き出しで出す |
| 判型・色 | ノートは B5／A4、教科書は B5／AB を置いた物ごとに選べる。ノート・連絡帳・ファイル・絵の具セットは色を5色から選べる |
| 表紙の文字 | ノート「ノート」、連絡帳「れんらく」、ファイル「ファイル」。左右反転しても文字は裏返らない |
| 置き場所 | 物の中心はグリッドの交点にだけ置ける。細かさは あらい／ふつう／こまかい（編集画面の上） |
| 寸法 | 一般的な製品の寸法を採用。出典は docs/spec.md |
| 開く物 | ノート・教科書・ドリル・連絡帳・筆箱・色鉛筆・パソコン・習字セット・パレット・絵の具セットは、閉じた形と開いた形を持つ |
| 左右反転 | その場かぎり（保存しない）。活動ごとに「反転してよい」を持ち、習字は既定で反転しない |
| 4人 | 2台ずつ向かい合わせ。内がわのフックは使えないので、掛ける物は外がわに寄せて描く |
| 保存 | この端末のブラウザ（localStorage）。別端末へは「データの書き出し・読み込み」のJSONで移す |

設計の理由は [docs/spec.md](docs/spec.md)。

## 直す・確かめる

- 用具・机の寸法・標準の配置: `src/data.js`（ここ1か所）
- 描き方: `src/draw.js`、画面: `src/app.js`、見た目: `src/style.css`

```bash
python3 scripts/build.py                     # src → dist
node apps/desk-layout/tests/test-app.mjs      # 不変条件
node apps/desk-layout/scripts/screenshot.mjs <出力先>   # 画面を撮る（playwright が要る）
```
