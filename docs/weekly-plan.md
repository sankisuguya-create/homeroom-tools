# 週案（時間割共同編集） — 設計 v0

教職員が1つの週案を共同で編集し、**B5で刷って教務必携に貼る**。あわせて、たんぽぽ時間割
（特別支援学級）への反映と、時数集計表（Excel）へのコピーを1操作で出す。

**この文書が仕様の正本。** 実装で迷ったらここに戻る。ここに書いていないことは決まっていない。

優先順位は **エラーの少なさ ＞ 認知的負荷の低さ ＞ 処理速度 ＞ 実装コスト**。
この文書の判断は、迷ったときすべてこの順で決めている。

## 0. 何を決めて、何を決めていないか

**凍結（v0 として確定。変えるならこの文書を書き換えてから）**

| | 決めたこと |
|---|---|
| 基盤 | GAS ウェブアプリ。校務ドメインの Google アカウントで認証する |
| 正本 | 週案スプレッドシート1枚。1行＝1コマ（4節） |
| コマの単位 | `(日付, 時程行, クラス)`。この3つで1コマが一意に決まる |
| コマの中身 | タイトル・詳細の2段。休み行はタイトルのみ |
| 層 | 基本時間割・学校全体・学年・専科・担任の5つ。**層は出どころの表示だけで、勝ち負けは決めない** |
| 勝ち負け | **あとから書かれたものが出る。** 時刻で決める（3節） |
| 権限 | **誰でもどのコマでも直せる。** 上位から来たコマは淡い塗りとラベルで示す |
| 重複 | 同じコマに2つ以上の層が書いたとき、週案を開いた時点で**警告窓を1回だけ**出す。同じ重複で二度は出さない |
| 生成 | 週案枠を作る時点で、基本時間割を全コマに流し込む。担任は差分だけ直す |
| 行事 | 年間行事予定スプレッドシートから読む。列の対応は対応表シートで持つ |
| 専科の表記 | 同じコマを、担任は教科名（音楽）で、専科はクラス名（2-1）で見る。データは1つ |
| リンク | タイトル欄・詳細欄それぞれに URL を1つ。**欄全体がリンクになる**（文字の一部ではない） |
| 出力① | たんぽぽ時間割へ「反映」ボタン。対応は対応表シートで持つ |
| 出力② | 時数集計表へ「クリップボードにコピー」ボタン。TSV。Excel のシートにそのまま貼れる |
| 印刷 | B5・1週1ページ。リンクは下線だけにして URL は刷らない |
| 土日 | 1列に畳み、上7行ぶんを土、下3行ぶんを日にする。授業行は持たず、行事だけ書く |
| 色 | 塗りは2色だけ（降ってきた／重なっている）。**層はラベルの文字が運ぶ**。色を外しても意味が残る |

**未決（実物を見てから決める。実装を止めるものではない）**

| | 決めていないこと | 止まるか |
|---|---|---|
| a | 貼り付け領域の実寸（教務必携の週案枠は何 mm × 何 mm か） | 止まらない。倍率と余白を設定で動かせるようにしてある |
| b | 年間行事予定スプレッドシートの列構成 | 止まらない。対応表シートで吸収する |
| c | たんぽぽ時間割スプレッドシートの構造 | **反映ボタンだけ止まる。** それ以外は動く |
| d | 時数集計表（Excel）の列順と行の並び | 止まらない。列順は設定シートで持つ |
| e | 時程（朝学習が何時から等）と、学年ごとの日課の違い | 止まらない。時程シートで持つ |
| f | クラス編成・専科の担当割 | 止まらない。クラスシートで持つ |
| g | **「実施」と「予定」を分けるか。** いまは1本で数えている。事前に書いた週案と事後に直した週案を別に持つなら、コマに版が要る | 止まらない |

## 1. なぜ GAS ウェブアプリなのか

要件のうち3つが、校務ドメインの中でしか成立しない。

| 要件 | ドメイン外のアプリ | GAS ウェブアプリ |
|---|---|---|
| 教職員の共同編集 | 校務アカウントで認証できない | ドメイン内認証がそのまま効く |
| ①たんぽぽ時間割へ反映 | 校務ドライブのシートに書けない | `SpreadsheetApp` |
| 行事の取り込み | 校務ドライブのシートを読めない | `SpreadsheetApp` |
| ②クリップボードへコピー | できる | できる |
| B5印刷 | できる | できる |

`prototypes/src/weekly-plan.html` は**印刷の版面と入力操作を紙で確かめるための元**であって、
運用の本体ではない。ノート評価と同じで、`build.py` が `prototypes/` と `gas/` の両方を作る。

## 2. 版面（画像の左ページに合わせる）

刷ったものを既存の週案枠の上に貼る。だから**枠の形は手帳に合わせる**。

```
        月    火    水    木    金   │土日
      ┌─────┬─────┬─────┬─────┬─────┼──┐
朝休み│     │     │     │     │     │土│  ← タイトルのみ
朝学習│漢字 │読聞 │読書 │漢字 │計算 │  │  ← 曜日ごとに違う。だから列は割る
      ├─────┼─────┼─────┼─────┼─────┤  │
  1   │題名 │題名 │題名 │題名 │題名 │  │
      │┈┈┈┈│┈┈┈┈│┈┈┈┈│┈┈┈┈│┈┈┈┈│  │  ← 上=タイトル 下=詳細
      │詳細 │詳細 │詳細 │詳細 │詳細 │  │
  2   │     │     │     │     │     │  │
      ├─────┼─────┼─────┼─────┼─────┤  │
業間  │     │     │     │     │     │  │
      ├─────┼─────┼─────┼─────┼─────┤  │
  3   │     │     │     │     │     │  │
  4   │     │     │     │     │     ├──┤
      ├─────┼─────┼─────┼─────┼─────┤日│
昼休み│給食・そうじ                     │  │
      ├─────┼─────┼─────┼─────┼─────┤  │
  5   │     │     │     │     │     │  │
  6   │     │     │     │     │     │  │
      ├─────┴─────┴─────┴─────┴─────┴──┤
週メモ│                                    │
      └────────────────────────────────────┘
```

**休み行も曜日ごとのセルにした。** 朝学習は曜日で中身が違う（月＝漢字、火＝計算…）。
帯にすると入らない。代わりに、休み行のコマを選ぶと編集バーに**「全曜日に入れる」**が出る。
給食・そうじのように5日とも同じものは、1回打って1回押せば済む。

**土日を1列に畳んだのは、そこに授業行が要らないから。** 手帳の左ページも日曜は隅に潰してある。
6日ぶんの授業行を刷ると1列あたりが 4mm 痩せて、詳細欄が使いものにならなくなる。
土のほうを広く取った（上7行ぶん）。**日曜より土曜のほうが書くことが多い。**

### 印刷の寸法

`@page { size: B5; margin: 可変 }`。B5 は 182 × 257mm。
**貼り付け領域の実寸が未決（0節 a）なので、余白と全体倍率を画面から動かせるようにした。**
1枚刷って手帳に当て、合う値を見つけたらその値を設定シートに書いて全職員で共有する。
これは実装の手抜きではなく、**測り直しを1人1回で終わらせるための設計**。

## 3. 層

5つある。**後のものが前のものを上書きする。**

| 層 | 誰が | 何を入れるか | 範囲 |
|---|---|---|---|
| 0 基本時間割 | 教務 | 各クラスの平常時の時間割 | 週案枠を作る時に流し込む |
| 1 学校全体 | 教務・管理職 | 訓練・朝会・全校練習・休業日 | 全クラス |
| 2 学年 | 学年主任 | 校外学習・学年体育・学年集会 | その学年の全クラス |
| 3 専科 | 音楽・図工・理科などの専科 | 自分が持つ時間 | 自分が担当するクラス |
| 4 担任 | 担任 | 各教科・行事・給食・コアタイム | 自分のクラス |

### 勝ち負けは時刻で決める。層では決めない

同じコマに2つ以上の層が書いたとき、**あとから書かれたほうが出る。**

*層の順で決めなかった理由*：層で決めると、上位がどれだけあとから入れても下位に負ける。
学年主任が水曜に「来週の火3は学年体育」と入れても、担任がすでに算数を入れていれば反映されず、
**しかも入れた学年主任自身の画面にも出ない**。これは黙って落ちる種類の誤りで、いちばん危ない。
時刻で決めれば、あとから直した人の意図がそのまま通り、それを担任がまた直せば担任が通る。
人が期待する順序と一致する。

（この欠陥は、プロトタイプを実際に動かして見つけた。層の順で組んだ初版は、
担任が先に入れたコマに学年主任が上書きできなかった。）

### 権限は分けない

**層は「どこから来たか」を示すだけで、誰が直せるかは分けない。** 上位から来たコマは
淡い塗りと右上のラベル（全体／学年／専）で示す。**塗りは色分けの上限に従って2色しか使わず、
層そのものはラベルの文字が運ぶ。** モノクロでも、色が見分けにくくても意味が残る。

*権限で止めなかった理由*：止めると、直前の変更（急な雨で校庭が使えない等）に担任が対応できず、
「システムに書いてある予定」と「実際にやったこと」がずれる。**ずれた記録は時数集計を壊す。**
エラーの少なさを優先するなら、直せるようにして誰が直したかを残すほうが安全。

### 重複警告

同じコマに2つ以上の層が書いたら、週案を開いた時点で警告窓を1回だけ出す。

```
  重なっているコマが 2 つあります

  11/20(金) 2校時  3-3
    学年「学年体育」              ← いま出ている（あとから書かれた）
    担任「算数」                  ← 出ていない
  ...
                          [ 見にいく ]  [ 閉じる ]
```

**閉じたらその重複については二度出さない**（コマの内容が変わったら出し直す）。
毎回出ると読まれなくなり、警告が機能しなくなる。

## 4. データの持ち方

正本は週案スプレッドシート1枚。**1行＝1コマ。**

| 列 | 中身 | 例 |
|---|---|---|
| `date` | 日付 | `2026-11-20` |
| `slot` | 時程行のID | `p2` |
| `class` | クラス | `3-3` |
| `title` | タイトル欄 | `算数` |
| `note` | 詳細欄 | `分数のたし算 ①` |
| `titleUrl` | タイトル欄のリンク | |
| `noteUrl` | 詳細欄のリンク | `https://...` |
| `subject` | 時数を数えるための教科コード | `math` |
| `layer` | どの層が最後に書いたか | `homeroom` |
| `teacher` | 担当者（専科のとき入る） | `ongaku@edu.nishi.or.jp` |
| `overridden` | 上位を上書きしたか | `学年` |
| `updatedBy` / `updatedAt` | 誰がいつ | |

書き込みは `LockService` で直列化し、**保存は差分だけ**送る。全面書き戻しにすると、
2人が同じ週を開いているときに片方の編集が消える。

### 付随するシート

| シート | 中身 |
|---|---|
| 設定 | 年度・学期の期間・印刷余白・倍率・時数表の列順 |
| 時程 | 時程行の定義（ID・表示名・種別・帯にするか） |
| クラス | クラス一覧・担任のメール |
| 教科 | 教科コード・表示名・時数表の列名・**時数に数えるか** |
| 基本時間割 | クラス × 曜日 × 時程行 → 教科 |
| 専科 | 専科のメール・担当教科・担当クラス |
| 対応表 | 年間行事予定シート／たんぽぽ時間割シートの ID と列の対応 |

**時程は学校ごとに違うので、行を固定しない。** 既定は
`朝休み・朝学習・1・2・業間休み・3・4・昼休み・5・6` の10行。

## 5. 専科の表記反転

音楽専科が 2-1 の音楽を設定したとき、**データは1つ、見え方が2つ**になる。

```
  cell = { title:"音楽", subject:"music", teacher:"ongaku@…", class:"2-1" }

  2-1 の担任の画面 →  音楽        （誰が来るかは決まっているので教科名でよい）
  音楽専科の画面   →  2-1         （どこへ行くかが知りたいのでクラス名）
```

判定は `cell.teacher === 開いている人` の1つだけ。専科が自分の週案を開くと、
持ちコマがクラス名で並ぶ。**専科は自分の画面から直接そのコマを直せる**（担任の画面にも即反映される）。

## 6. 出力

### ① たんぽぽ時間割へ反映

特別支援学級の児童は交流学級の授業に入る。だから**たんぽぽ時間割は、各交流学級の時間割の
抜き出し**になる。「反映」ボタンで、対応表シートに書いたクラス対応にしたがって書き込む。

**この対応表の中身が未決（0節 c）。** たんぽぽ時間割の実物を見るまで作れない。
ボタンと書き込み口は先に作り、対応表が空のあいだは押しても「対応表が未設定です」と返す。

### ② 時数集計表へコピー

画像の右ページ下部の表に合わせる。列は

```
国語 社会 算数 理科 生活 音楽 図工 家庭 体育 道徳 外国語 総合 学活   計
```

**学年によって列が変わる**（3年に家庭は無い、生活は1・2年だけ、外国語は5・6年）ので、
列順は設定シートに持つ。行は `実施 / 予定` と `累計`。

「クリップボードにコピー」で TSV をクリップボードに置き、Excel の当該週シートに貼る。
**Excel を GAS から直接触らない。** OneDrive/SharePoint 経由の書き込みは認証も同期も壊れやすく、
「エラーの少なさ」に反する。人が1回貼るほうが確実で、操作も1つしか増えない。

数えるのは `教科シートの「時数に数えるか」が真のコマ`のみ。給食・朝の会・行事は数えない。

## 7. 認知的負荷をどこで下げたか

| 手 | 何が減るか |
|---|---|
| 基本時間割を生成時に流し込む | 担任の入力が「週30コマ」から「変更した数コマ」になる |
| 休み行を全列ぶち抜きの帯にする | 同じ予定を5回入れずに済む |
| 上位を淡色＋鍵で示す | 「これは自分が決めたことか」を色で判断できる |
| 重複警告を開いたとき1回だけ | 毎回出る警告は読まれなくなる |
| 専科の表記を見る人で変える | 担任は「音楽」、専科は「2-1」。どちらも読み替えが要らない |
| リンクを欄単位にする | 文字の一部を選んでリンクを張る操作を無くす |
| 印刷を1週1ページに固定 | 何枚刷るか・どこで切るかを毎回考えずに済む |
